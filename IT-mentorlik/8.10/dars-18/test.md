# 18-dars tezkor test

1. Sichqoncha ustida bo'lganda stil? — `:hover`
2. Juft qatorlar? — `:nth-child(even)`
3. Element oldiga matn/belgi qo'shish? — `::before` (+ `content`)
4. Aylantirganda ekranda joyida qoladigan tugma? — `position: fixed`
5. Aylantirganda tepaga yopishadigan menyu? — `position: sticky; top: 0`
6. `absolute` element nimaga nisbatan joylashadi? — Eng yaqin `position: relative` (yoki boshqa non-static) otaga
7. Qaysi element ustida turishini boshqarish? — `z-index`
