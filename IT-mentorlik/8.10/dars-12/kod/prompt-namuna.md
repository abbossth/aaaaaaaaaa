# Prompt namunalari (8.10)

## 1. Sahifa yaratish
```
Sen tajribali veb-dasturchi va o'qituvchisan.
8-sinf o'quvchisi uchun "[MAVZU]" haqida bitta HTML sahifa yarat.

Talablar:
- faqat HTML (CSS va JavaScript ishlatma)
- semantik teglar: header, nav, main, section, article, footer
- kamida 1 ta jadval, 1 ta tartibli va 1 ta tartibsiz ro'yxat
- rasmlar uchun https://picsum.photos/400/250 ishlat, har bir rasmda alt bo'lsin
- 1 ta YouTube iframe (VIDEO_ID ni o'zim qo'yaman)
- har bir bo'lim oldidan o'zbek tilida qisqa izoh (<!-- -->) yoz
```

## 2. Kodni tushunish
```
Mana bu kodni 8-sinf o'quvchisiga tushuntir, har bir tegni alohida:
<figure><img src="..." alt="..."><figcaption>...</figcaption></figure>
```

## 3. Xatoni topish
```
Mening HTML kodimda xato bormi? Xatoni o'zing tuzatma, faqat qayerda ekanini va nega xato ekanini ayt:
[kod]
```
