# 8.10 — Web Full-stack dasturlash: umumiy reja

**Guruh:** 8.10 (yangi ochilgan, o'quvchilar noldan boshlaydi)
**Yo'nalish:** Web Full-stack dasturlash (8-sinf standarti asosida)
**Hajm:** 70 dars × 80 daqiqa, haftasiga 3 marta, 30-sentabrdan

## Guruhga xos yondashuv
- O'quvchilar hali hech narsani bilmaydi, shuning uchun **birinchi 6 dars** kompyuter savodxonligi, internet va algoritmik fikrlashga (Flowgorithm) ajratilgan.
- Har bir darsda **vizual natija** bo'ladi: sahifa, o'yin, bot. Nazariya minimal, "qil va ko'r" usuli qo'llaniladi.
- Standartdagi ketma-ketlik saqlangan: HTML → CSS → Git/deploy → JavaScript → Python → Telegram bot → ma'lumotlar bazasi.
- Django va DRF 70 dars ichiga sig'maydi. Ular rasmiy dasturning qolgan qismi sifatida keyingi darslarga (71+) qoldiriladi.
- **Yil davomidagi yakuniy loyiha:** jamoaviy **Telegram bot startap** (Demo Day'da taqdim etiladi).

## Yil davomida o'quvchi yaratadigan loyihalar portfeli
1. "Men haqimda" shaxsiy sahifa (HTML)
2. Jamoaviy landing page, internetda joylashtirilgan (HTML/CSS/Git/Netlify)
3. JS mini o'yinlar va To-Do ilova
4. Quiz ilova + ob-havo ilovasi (JS + API)
5. Python terminal o'yini ("Pokemon janglari")
6. Telegram bot startap + ma'lumotlar bazasi (Python + aiogram + SQL)

## Rasmiy dasturning keyingi qismi (71-darsdan keyin)
