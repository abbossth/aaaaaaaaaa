# 24-dars. Git va GitHub asoslari, GitHub Pages/Netlify'ga deploy, SEO

**Guruh:** 8.10 | **Turi:** 📘 Mavzu | **Davomiyligi:** 80 daqiqa

## Maqsad
- Git nima uchun kerakligini tushunadi: o'yindagi "saqlash nuqtasi" (save point) kabi versiyalar tarixi.
- `git init`, `add`, `commit`, `push` buyruqlari bilan loyihani GitHub'ga yuklaydi (yoki VS Code'ning Source Control paneli orqali).
- GitHub Pages yoki Netlify orqali saytini internetga joylaydi (deploy) va havolasini ulashadi.
- SEO asoslarini biladi: `title`, `meta description`, semantik teglar, `alt`, Open Graph (Telegram'dagi preview).

## Dars rejasi

| Vaqt | Bosqich | Nima qilinadi |
|---|---|---|
| 0–5 | **Hook** | *"Dars oxirida saytingiz havolasini onangizga Telegram'da yuborasiz va u telefonidan ochadi!"* Mentor o'z saytini telefonda ochib ko'rsatadi |
| 5–15 | **Git nima?** | Save point analogiyasi. Git va GitHub farqi. 3 hudud (sodda: o'zgartirish → tayyorlash → saqlash) |
| 15–40 | **Amaliyot 1** | VS Code Source Control orqali: Initialize → Commit → Publish to GitHub |
| 40–58 | **Deploy** | GitHub Pages (Settings → Pages) yoki Netlify → havolani telefonda ochish 📱 |
| 58–72 | **SEO + OG** | `kod/seo-head.html` → push → Telegram'da havola preview'si |
| 72–80 | **Yakun** | Hamma havolasini Telegram guruhga tashlaydi 🎉 XP |
