# 24-dars amaliy topshiriq

## 🟢 1-qadam (+10 XP): GitHub'ga yuklash
1. VS Code'da `landing` papkasini oching.
2. Source Control → Initialize → izoh → Commit.
3. "Publish to GitHub" → **public** repository → GitHub'ga kiring.
4. GitHub saytida reponi oching: fayllaringiz ko'rinyaptimi?

## 🟡 2-qadam (+20 XP): Deploy
5. Repo → Settings → Pages → Source: "Deploy from a branch" → Branch: `main` → Save.
6. 1–2 daqiqa kuting → havola paydo bo'ladi. Telefoningizda oching! 📱
7. Havolani Telegram guruhga yuboring.

## 🔴 3-qadam (+10 XP): SEO va preview
8. `<head>` ga `kod/seo-head.html` dagi teglarni qo'shing (o'z ma'lumotlaringiz bilan) va favicon.
9. O'zgarishni commit + push qiling (Source Control → Commit → **Sync Changes**). Sayt avtomatik yangilanadimi?
10. Havolani Telegram'da yuboring: rasm va sarlavha chiqdimi?
11. `README.md` fayli: sayt nomi, havolasi, skrinshot.
