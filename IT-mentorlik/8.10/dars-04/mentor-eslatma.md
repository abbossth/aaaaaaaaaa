# 4-dars mentor eslatmasi

## Ko'p uchraydigan xatolar (Flowgorithm)
| Xato | Yechim |
|---|---|
| Declare qilinmagan o'zgaruvchidan foydalanish | Flowgorithm xato beradi. Avval "quti yarat", keyin ishlat |
| Kasr son Integer'ga yoziladi | Real turini tanlash |
| Output'da matn va o'zgaruvchi qo'shilmaydi | `"Salom, " & ism` (Flowgorithm'da `&` bilan birlashtiriladi) |
| O'zgaruvchi nomida probel yoki apostrof (`bo'y`) | Faqat lotin harflar, raqam va `_` |

## Maslahatlar
- "Robot-o'quvchi" o'yinida xavfsizlikni ta'minlang: yo'lda to'siq bo'lmasin.
- Flowgorithm'ning "Source code" oynasini ko'rsatib qo'ying (Tools → Source Code Viewer). U blok-sxemani Python va JavaScript kodiga aylantiradi. *"Ko'ryapsizmi? Keyinroq aynan shunday kod yozasiz!"* — bu katta motivatsiya.
- Flowgorithm'da tilni sozlashda o'zbek tili yo'q. Ingliz tilini qoldiring, bu ham foydali.
