# 4-dars: Flowgorithm namunalari

Flowgorithm (.fprg) fayllari grafik muharrirda yaratiladi. Quyida har bir namunaning mantig'i psevdokod ko'rinishida berilgan, mentor ularni darsda ekranda yig'adi.

## Ikki son yig'indisi
```
Declare Integer a, b, yigindi
Output "Birinchi son:"
Input a
Output "Ikkinchi son:"
Input b
Assign yigindi = a + b
Output "Yig'indi: " & yigindi
```

## Daqiqa → soat
```
Declare Integer daqiqa, soat, qoldiq
Input daqiqa
Assign soat = daqiqa / 60
Assign qoldiq = daqiqa % 60
Output soat & " soat " & qoldiq & " daqiqa"
```
