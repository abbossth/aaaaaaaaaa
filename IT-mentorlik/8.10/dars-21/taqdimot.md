# 21-dars slaydlari: Figma 🎨

## 1-slayd
**Dizayner chizadi → dasturchi quradi**

## 2-slayd — Kim nima qiladi?
🎨 **UI dizayner:** qanday ko'rinadi (rang, shrift, joylashuv)
🧠 **UX dizayner:** qanday ishlatiladi (qulaylik, mantiq)
👨‍💻 **Front-end dasturchi:** maketni kodga aylantiradi

## 3-slayd — Figma asboblari
`F` Frame (ekran) · `R` Rectangle · `O` Ellipse · `T` Text · `Shift+A` Auto Layout
Chap panel: Layers · O'ng panel: Design (rang, o'lcham, shrift)

## 4-slayd — Auto Layout = Flexbox! 🤯
| Figma | CSS |
|---|---|
| Direction → / ↓ | `flex-direction: row / column` |
| Spacing | `gap` |
| Padding | `padding` |
| Alignment | `justify-content` / `align-items` |
