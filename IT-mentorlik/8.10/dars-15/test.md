# 15-dars tezkor test

1. Flexbox'ni yoqish? — Ota elementga `display: flex`
2. Elementlarni asosiy o'q bo'yicha markazga? — `justify-content: center`
3. Ko'ndalang o'q bo'yicha markazga? — `align-items: center`
4. Elementlarni ustunga terish? — `flex-direction: column`
5. Elementlar orasida bo'shliq? — `gap`
6. Sig'magan elementlar keyingi qatorga o'tishi uchun? — `flex-wrap: wrap`
