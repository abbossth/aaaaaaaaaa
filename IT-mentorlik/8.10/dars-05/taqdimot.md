# 5-dars slaydlari: Shartlar

## 1-slayd
**AGAR ... BO'LSA → ... AKS HOLDA → ...** 🔀

## 2-slayd — Hayotdagi shartlar
🚦 Agar yashil bo'lsa → yur, aks holda → to'xta
🔐 Agar parol to'g'ri bo'lsa → kir, aks holda → "Xato parol"
🌧 Agar yomg'ir yog'sa → soyabon ol

## 3-slayd — Blok-sxemada
```
      ◇ son > 0 ?
    Ha /     \ Yo'q
      ▭       ▭
"Musbat"   "Musbat emas"
```

## 4-slayd — Taqqoslash operatorlari
`>` katta · `<` kichik · `>=` katta yoki teng · `<=` kichik yoki teng · `==` teng · `!=` teng emas
❗ `=` — qiymat berish, `==` — taqqoslash

## 5-slayd — Mantiqiy operatorlar
| Operator | Ma'nosi | Misol |
|---|---|---|
| `and` (VA) | Ikkalasi ham rost | yosh >= 14 **and** yosh <= 16 |
| `or` (YOKI) | Kamida bittasi rost | kun == "shanba" **or** kun == "yakshanba" |
| `not` (EMAS) | Teskarisi | **not** (yomg'ir) |

## 6-slayd — Juft yoki toq?
`son % 2 == 0` → juft
`%` — bo'lishdan qolgan qoldiq: `7 % 2 = 1`, `8 % 2 = 0`

## 7-slayd — Ichma-ich shart: baho
ball ≥ 86 → "5" · ball ≥ 71 → "4" · ball ≥ 56 → "3" · aks holda → "2"
