# 13-dars. CSS ulash usullari, selektorlar, ranglar, shriftlar

**Guruh:** 8.10 | **Turi:** 📘 Mavzu | **Davomiyligi:** 80 daqiqa

## Maqsad
- CSS nima ekanini va uning HTML bilan munosabatini tushunadi ("skelet → kiyim").
- CSS ulashning 3 usulini (inline, internal, external) biladi va nega external eng yaxshi ekanini tushunadi.
- CSS sintaksisi (selektor { xossa: qiymat; }) va asosiy selektorlarni (teg, `.class`, `#id`, guruh, ichma-ich) qo'llaydi.
- Ranglar (nomi, HEX, RGB) va matn xossalarini (`font-family`, `font-size`, `font-weight`, `text-align`, `color`, `line-height`) ishlatadi. Google Fonts ulaydi.
