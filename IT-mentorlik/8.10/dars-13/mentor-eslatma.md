# 13-dars mentor eslatmasi

## Ko'p uchraydigan xatolar
| Xato | Yechim |
|---|---|
| CSS ishlamaydi | `<link>` dagi fayl nomi/yo'li, `rel="stylesheet"` unutilgan |
| `;` yoki `}` unutilgan → keyingi qoidalar ham ishlamaydi | VS Code ranglariga e'tibor bering |
| `.` va `#` chalkashligi | "Class — nuqta (ko'p bo'ladi), ID — panjara (bitta)" |
| Selektorda `class=` yozilgan: `class=muhim {}` | `.muhim` |
| Google Fonts ishlamaydi | `<link>` `<head>` da bo'lishi kerak, shrift nomi aniq yozilishi kerak |

## Maslahat
Sahifaga CSS birinchi marta berilganda o'quvchilar juda xursand bo'ladi. "Oldin va keyin" skrinshotlarini albatta so'rang va maqtang 🎉
