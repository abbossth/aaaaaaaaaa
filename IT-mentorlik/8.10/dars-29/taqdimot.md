# 29-dars slaydlari: JavaScript — sahifaning miyasi 🧠

## 1-slayd
🦴 HTML — skelet · 👕 CSS — kiyim · 🧠 **JavaScript — miya**

## 2-slayd — JS nima qila oladi?
🎮 O'yinlar · 🔘 Tugma bosilganda harakat · 📝 Formalarni tekshirish · 🌤 Ob-havo ma'lumotini olish · 🌙 Dark mode

## 3-slayd — Console = JS maydonchasi
`F12` → **Console**
```js
2 + 2
console.log("Salom, dunyo!");
alert("Diqqat!");
```

## 4-slayd — O'zgaruvchi = quti 📦 (Flowgorithm'dagi Declare!)
```js
let yosh = 14;         // o'zgarishi mumkin
const ism = "Aziz";    // o'zgarmas
yosh = 15;             // ✅
```
Nomlash: **camelCase** → `meningYoshim`, `sevimliRang`

## 5-slayd — Ma'lumot turlari
| Tur | Misol |
|---|---|
| `string` (matn) | `"Salom"`, `'Aziz'` |
| `number` (son) | `14`, `3.5` |
| `boolean` (ha/yo'q) | `true`, `false` |
| `undefined` | qiymat berilmagan |
`typeof 14` → `"number"`

## 6-slayd — Flowgorithm → JS
| Flowgorithm | JavaScript |
|---|---|
| Declare | `let x;` |
| Input | `prompt("...")` |
| Assign | `x = 5;` |
| Output | `console.log(x)` / `alert(x)` |

## 7-slayd — JS'ni HTML'ga ulash
```html
<body>
  ...
  <script src="app.js"></script>
</body>
```
