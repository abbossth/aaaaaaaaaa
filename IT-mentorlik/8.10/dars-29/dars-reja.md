# 29-dars. JavaScript'ga kirish: console, o'zgaruvchilar, ma'lumot turlari

**Guruh:** 8.10 | **Turi:** 📘 Mavzu | **Davomiyligi:** 80 daqiqa

## Maqsad
- JavaScript nima uchun kerakligini tushunadi: HTML — skelet, CSS — kiyim, JS — **miya**.
- Brauzer Console'ida (`F12`) JS yozadi va natijani ko'radi.
- JS'ni HTML'ga ulaydi (`<script src="app.js">`).
- `let` va `const` bilan o'zgaruvchi e'lon qiladi, camelCase'da nomlaydi.
- Ma'lumot turlarini biladi: `string`, `number`, `boolean`, `undefined`, `null`, `typeof`.
- `console.log`, `alert`, `prompt` bilan ishlaydi. Flowgorithm'dagi "Declare/Input/Output"ni JS bilan bog'laydi.
