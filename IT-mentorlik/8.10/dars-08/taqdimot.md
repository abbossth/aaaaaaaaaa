# 8-dars slaydlari: Rasmlar va havolalar

## 1-slayd
🔗 **Internet = havolalar to'ri**

## 2-slayd — Atribut
```html
<teg atribut="qiymat">...</teg>
<img src="mushuk.jpg" alt="Oq mushuk" width="300">
```
Atribut — tegga qo'shimcha ma'lumot

## 3-slayd — Matn teglari
`<strong>` **muhim** · `<em>` *urg'u* · `<mark>` belgilangan · `<blockquote>` iqtibos · `<hr>` chiziq

## 4-slayd — Rasm
```html
<img src="rasmlar/men.jpg" alt="Mening rasmim" width="250">
```
❗ `alt` — rasm ko'rinmasa chiqadigan matn. Ko'zi ojizlar uchun ekran o'quvchi dastur aynan shuni o'qiydi

## 5-slayd — Yo'llar
`men.jpg` — shu papkada
`rasmlar/men.jpg` — ichki papkada
`../men.jpg` — bir papka yuqorida
`https://picsum.photos/300` — internetda

## 6-slayd — Havolalar
```html
<a href="hobbi.html">Hobbim</a>                        <!-- boshqa sahifa -->
<a href="https://kun.uz" target="_blank">Kun.uz</a>    <!-- yangi tabda -->
<a href="#orzu">Orzuimga o'tish</a>                   <!-- sahifa ichida -->
<a href="mailto:aziz@mail.uz">Email</a>
<a href="tel:+998901234567">Qo'ng'iroq</a>
```

## 7-slayd — Rasm-havola
```html
<a href="https://youtube.com"><img src="youtube.png" alt="YouTube"></a>
```
