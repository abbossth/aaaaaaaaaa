# 32-dars. Funksiyalar: parametr, return, arrow

**Guruh:** 8.10 | **Turi:** 📘 Mavzu | **Davomiyligi:** 80 daqiqa

## Maqsad
- Funksiya nima uchun kerakligini tushunadi: bir marta yoz — ko'p marta ishlat.
- `function nom(parametr) { return ... }` va arrow `(x) => x * 2` ko'rinishlarini yozadi.
- Parametr, argument, `return` va default qiymatni farqlaydi.
- `return` va `console.log` farqini tushunadi.
- Mini kalkulyator funksiyalari kutubxonasini yaratadi.
