# 6-dars slaydlari: Sikllar

## 1-slayd
**100 marta yozish? Yo'q, rahmat! 🔁**

## 2-slayd — Sikl = takrorlash
Bir xil harakatni ko'p marta bajarish:
🏃 Stadion atrofida 5 aylana · 🎵 Qo'shiqni takrorlash · 📩 1000 ta odamga SMS

## 3-slayd — For sikli (necha marta — ma'lum)
```
For i = 1 to 10
    Output i
```
`i` — hisoblagich: 1, 2, 3, ..., 10

## 4-slayd — While sikli (shart bajarilguncha)
```
While parol != "1234"
    Input parol
```
Qachon to'xtashi oldindan ma'lum emas

## 5-slayd — Yig'uvchi o'zgaruvchi
```
summa = 0
For i = 1 to 100
    summa = summa + i
Output summa   → 5050
```
Ertak: yosh Gauss bu masalani 1 daqiqada yechgan 😉

## 6-slayd — ⚠️ Cheksiz sikl
```
i = 1
While i > 0
    i = i + 1   ← hech qachon tugamaydi!
```
Algoritmning "cheklilik" xossasi buziladi
