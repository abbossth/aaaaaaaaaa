# 19-dars amaliy topshiriq

Asosiy amaliyot — CSS Battle (`challenge.md`). Tez tugatganlar uchun:

## 🟢 Oson (+5 XP)
CSS bilan **svetofor** chizing: qora to'rtburchak ichida 3 ta doira (qizil, sariq, yashil).

## 🟡 O'rta (+10 XP)
CSS bilan **O'zbekiston bayrog'i** (ko'k, oq, yashil yo'laklar va qizil ingichka chiziqlar, yarim oysiz).

## 🔴 Qiyin (+20 XP)
Bayroqqa **yarim oy** qo'shing: oq doira ustiga biroz siljitilgan ko'k doira. Bonus: 12 ta yulduzni `✦` belgisi bilan joylashtiring.
