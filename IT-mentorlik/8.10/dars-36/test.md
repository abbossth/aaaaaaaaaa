# 36-dars tezkor test

1. Forma yuborilganda sahifa yangilanmasligi uchun? — `event.preventDefault()`
2. Formaning qaysi eventi? — `submit`
3. localStorage'ga saqlash? — `localStorage.setItem("kalit", qiymat)`
4. Massivni localStorage'ga saqlashdan oldin? — `JSON.stringify()` bilan matnga aylantirish
5. Matnni qayta massivga? — `JSON.parse()`
6. localStorage ma'lumotlarini brauzerda qayerda ko'ramiz? — F12 → Application → Local Storage
7. Massivdan elementni o'chirish? — `splice(index, 1)`
