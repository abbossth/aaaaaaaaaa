# 7-dars. HTML hujjat strukturasi, VS Code, birinchi sahifa

**Guruh:** 8.10 | **Turi:** 📘 Mavzu | **Davomiyligi:** 80 daqiqa

## Maqsad
- HTML nima ekanini va teg, element, atribut tushunchalarini biladi.
- HTML hujjat skeletini (`<!DOCTYPE>`, `html`, `head`, `body`) tushunadi.
- VS Code'da fayl yaratadi, Emmet (`!` + Tab) va Live Server bilan ishlaydi.
- Sarlavha (`h1`–`h6`), paragraf (`p`) va qator tashlash (`br`) bilan birinchi sahifasini yaratadi.

## Kerakli narsalar
- VS Code + **Live Server** kengaytmasi (har bir kompyuterda)

## Dars rejasi

| Vaqt | Bosqich | Nima qilinadi |
|---|---|---|
| 0–5 | **Hook** | Istalgan saytda (masalan, kun.uz) `Ctrl+U` (sahifa kodi). *"Har bir sayt ichida mana shunday kod bor. Bu HTML. Bugun uni o'zingiz yozasiz."* Keyin `F12` orqali sarlavhani o'zgartirib "yangilik" yasash (kulgili "fake news") 😄 |
| 5–10 | **Takrorlash** | 6-dars testi. 2-darsdagi "spoiler"ni eslash: `salom.html` |
| 10–25 | **Yangi mavzu** | HTML = sahifaning "skeleti". Teg, ochuvchi/yopuvchi, element, atribut. Skelet: `head` (ko'rinmaydigan "miya"), `body` (ko'rinadigan "tana"). VS Code tanishuvi |
| 25–35 | **Jonli kod** | Mentor ekranda: papka ochish → `index.html` → `!` + Tab → sarlavhalar → Live Server ("Go Live") → saqlaganda avtomatik yangilanish |
| 35–60 | **Amaliyot** | `amaliy-topshiriq.md` |
| 60–72 | **Challenge** | `challenge.md`: "Teg ovchisi" |
| 72–80 | **Yakun** | 2–3 o'quvchi sahifasini ekranda ko'rish, XP, uyga vazifa |

## Baholash (XP)
- Birinchi sahifa ishlaydi +10 · Amaliyot +5/+10/+20 · Challenge +20/+10/+5
