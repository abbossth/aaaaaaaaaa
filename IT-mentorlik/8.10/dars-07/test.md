# 7-dars tezkor test

1. HTML nima? — Veb-sahifa tuzilmasini belgilash tili
2. Sahifadagi eng katta sarlavha tegi? — `<h1>`
3. Brauzer tabidagi nom qaysi tegda yoziladi? — `<title>`
4. Ko'rinadigan kontent qaysi tegda bo'ladi? — `<body>`
5. Paragraf tegi? — `<p>`
6. VS Code'da HTML skeletini tez yaratish? — `!` + Tab
7. Yopuvchi teg qanday belgi bilan boshlanadi? — `</`
