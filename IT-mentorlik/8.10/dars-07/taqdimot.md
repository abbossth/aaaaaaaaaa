# 7-dars slaydlari: HTML — birinchi sahifa

## 1-slayd
🌐 **HTML — har bir saytning skeleti**

## 2-slayd — Sayt = odam
🦴 **HTML** — skelet (tuzilma)
👕 **CSS** — kiyim (dizayn)
🧠 **JavaScript** — miya (harakat)

## 3-slayd — Teg
```html
<h1>Salom, dunyo!</h1>
```
`<h1>` ochuvchi teg · `Salom, dunyo!` matn · `</h1>` yopuvchi teg
Hammasi birga — **element**

## 4-slayd — HTML skeleti
```html
<!DOCTYPE html>
<html lang="uz">
<head>
  <meta charset="UTF-8">
  <title>Mening sahifam</title>
</head>
<body>
  <h1>Salom, dunyo!</h1>
  <p>Bu mening birinchi sahifam.</p>
</body>
</html>
```

## 5-slayd — head va body
🧠 **head** — ko'rinmaydi: sarlavha (tab nomi), kodlash, sozlamalar
🧍 **body** — ko'rinadi: matn, rasmlar, tugmalar

## 6-slayd — Sarlavhalar
`<h1>` eng katta ... `<h6>` eng kichik
Qoida: sahifada **bitta** `h1`

## 7-slayd — VS Code sehrlari ✨
`!` + Tab → skelet · `Ctrl+S` → saqlash · "Go Live" → avtomatik yangilanish
`Shift+Alt+F` → kodni chiroyli qilish
