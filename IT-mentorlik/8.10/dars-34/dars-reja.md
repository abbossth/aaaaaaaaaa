# 34-dars. DOM: elementlarni topish va o'zgartirish

**Guruh:** 8.10 | **Turi:** 📘 Mavzu | **Davomiyligi:** 80 daqiqa

## Maqsad
- DOM nima ekanini tushunadi: HTML sahifa = JavaScript boshqara oladigan "daraxt" 🌳.
- Elementni topadi: `getElementById`, `querySelector`, `querySelectorAll`.
- Matn (`textContent`, `innerHTML`), stil (`style`), atribut (`src`, `href`) va klass (`classList`) o'zgartiradi.
- Yangi element yaratadi (`createElement`, `append`) va massivdan ro'yxat chizadi.
- Birinchi marta **JS + HTML + CSS birga** ishlaydi — "sahifa jonlandi!"
