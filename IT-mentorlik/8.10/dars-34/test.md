# 34-dars tezkor test

1. DOM nima? — HTML sahifaning JavaScript boshqara oladigan obyektlar daraxti
2. `id="ism"` elementni topish? — `document.getElementById("ism")`
3. Klassi `karta` bo'lgan birinchi element? — `document.querySelector(".karta")`
4. `textContent` va `innerHTML` farqi? — `innerHTML` HTML teglarni ham tushunadi
5. CSS'dagi `background-color` JS'da qanday yoziladi? — `style.backgroundColor`
6. Yangi `<li>` yaratish? — `document.createElement("li")`
7. `getElementById` `null` qaytardi. Sabab? — `id` noto'g'ri yoki script element'dan oldin yuklangan
