# 17-dars. CSS Grid + Grid Garden o'yini

**Guruh:** 8.10 | **Turi:** 📘 Mavzu | **Davomiyligi:** 80 daqiqa

## Maqsad
- Grid va Flexbox farqini tushunadi: Grid — ikki o'lchamli (qator **va** ustun), Flexbox — bir o'lchamli.
- `display: grid`, `grid-template-columns/rows`, `fr` birligi, `repeat()`, `gap` ni qo'llaydi.
- Elementni bir necha ustun/qatorga cho'zadi: `grid-column: span 2`, `grid-row`.
- `repeat(auto-fit, minmax(200px, 1fr))` bilan media query'siz moslashuvchan galereya yasaydi.
- Grid Garden o'yinida 28 darajani o'tadi.
