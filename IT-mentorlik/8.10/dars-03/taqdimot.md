# 3-dars slaydlari: Internet qanday ishlaydi?

## 1-slayd
**Internet qanday ishlaydi?** 🌐
Video 1 soniyada sizga qanday yetib keladi?

## 2-slayd — Client va Server
💻 **Client (mijoz)**: so'rov yuboradi (sizning brauzeringiz yoki telefoningiz)
🖥 **Server**: javob beradi (24/7 ishlaydigan kuchli kompyuter)
Restoran: siz = client, oshxona = server, ofitsiant = internet

## 3-slayd — IP-manzil
Internetdagi har bir qurilmaning "uy manzili":
`142.250.185.78` ← Google serverlaridan biri
Lekin kim raqamlarni eslab qoladi? 🤯

## 4-slayd — DNS = Internetning telefon kitobi 📒
Siz: `youtube.com`
DNS: "Bu nom → `142.250.x.x`"
Kontaktlardagi "Onam" ismi va uning ortidagi telefon raqami kabi.

## 5-slayd — Domen
Saytning oson eslanadigan nomi: `google.com`, `kun.uz`, `my.gov.uz`
`.uz` → O'zbekiston · `.com` → tijorat · `.org` → tashkilot · `.edu` → ta'lim
Domen sotib olinadi, yiliga ~10–15$

## 6-slayd — Hosting
Saytingiz fayllari turadigan server'dan **joy ijarasi**.
Uy = hosting, manzil = domen
Bepul hosting: **GitHub Pages, Netlify, Vercel** (buni 24-darsda qilamiz!)

## 7-slayd — So'rov yo'li
Brauzer → DNS → Server → Javob (HTML/CSS/JS) → Ekran
⏱ Hammasi **~0.3 soniyada**!

## 8-slayd — Front-end va Back-end
| Front-end 🎨 | Back-end ⚙️ |
|---|---|
| Ko'rinadi | Ko'rinmaydi |
| Tugmalar, ranglar, sahifa | Login, parol tekshirish, baza |
| HTML, CSS, JS | Python, Django, SQL |
| Restoran zali | Restoran oshxonasi |

## 9-slayd — Misol: Telegram
Front-end: chat oynasi, stikerlar, tugmalar
Back-end: xabarni saqlash, yetkazish, "o'qildi" belgisi
