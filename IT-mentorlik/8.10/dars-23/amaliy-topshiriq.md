# 23-dars amaliy topshiriq

Landing page'ingizga (22-dars) animatsiyalar qo'shing.

## 🟢 Oson (+5 XP)
1. Barcha tugmalarga hover: rang o'zgarishi + `scale(1.05)` + `transition`.
2. Kartochkalarga hover: yuqoriga ko'tarilish (`translateY(-8px)`) va soyaning kattalashishi.

## 🟡 O'rta (+10 XP)
3. Hero sarlavhasi sahifa ochilganda pastdan "suzib" chiqsin: `@keyframes` + `opacity: 0 → 1` + `translateY(30px → 0)` + `forwards`.
4. "Ro'yxatdan o'tish" tugmasi e'tiborni tortish uchun sekin pulsatsiya qilsin.

## 🔴 Qiyin (+20 XP)
5. Kartochkalar ketma-ket paydo bo'lsin: har biriga turli `animation-delay` (0.1s, 0.2s, 0.3s).
6. Faqat CSS bilan "yozayotgan mashinka" effekti: matn harfma-harf paydo bo'ladi (`steps()` + `width` + `overflow: hidden` + miltillovchi kursor).
