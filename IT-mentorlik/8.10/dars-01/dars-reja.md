# 1-dars. IT olamiga xush kelibsiz! Kompyuter qanday ishlaydi?

**Guruh:** 8.10 | **Turi:** 📘 Mavzu | **Davomiyligi:** 80 daqiqa

## Maqsad
- O'quvchilar bir-biri va mentor bilan tanishadi, kurs nima berishini tushunadi.
- IT kasblari (front-end, back-end, full-stack, bot dasturchi, DevOps, AI) haqida tasavvur hosil qiladi.
- Kompyuterning asosiy qismlarini (CPU, RAM, xotira, kiritish/chiqarish qurilmalari) biladi.
- XP liga qoidalarini tushunadi va o'z profilini ochadi.

## Kerakli narsalar
- Proyektor, `taqdimot.md` bo'yicha slaydlar
- Stikerlar yoki A4 qog'ozlar (kasb kartalari uchun)
- XP liga jadvali (Google Sheets), [README](../../README.md#gamifikatsiya-tizimi--xp-liga) bo'yicha
- Iloji bo'lsa, ochiq kompyuter qismlari: eski RAM, HDD yoki kuller

## Dars rejasi

| Vaqt | Bosqich | Nima qilinadi |
|---|---|---|
| 0–5 | **Hook** | Savol: *"Bugun ertalabdan beri qancha dasturdan foydalandingiz?"* Sanaymiz: budilnik, Telegram, YouTube, Click, Yandex Go... Xulosa: *"Hammasini kimdir yozgan. Bu yil sizlar ham yozasiz."* |
| 5–15 | **Tanishuv o'yini** | "2 haqiqat + 1 yolg'on": har bir o'quvchi o'zi haqida 3 ta gap aytadi, qolganlar yolg'onini topadi. Mentor birinchi bo'lib boshlaydi. |
| 15–30 | **IT kasblari** | Slaydlar (5–9-slayd): har bir kasb, u nima qiladi, qanday ilova yaratadi, O'zbekistonda maoshi qancha. *"Bu kurs oxirida siz sayt va Telegram bot yaratasiz"* |
| 30–45 | **Kompyuter qanday ishlaydi** | Oshxona analogiyasi: CPU = oshpaz, RAM = oshxona stoli, SSD/HDD = muzlatgich, klaviatura/sichqoncha = buyurtma, monitor = tayyor taom. Jonli ko'rsatish: Vazifalar dispetcheri (Task Manager) orqali CPU va RAM yuklanishi. |
| 45–60 | **Amaliyot** | `amaliy-topshiriq.md`: "Kompyuterim pasporti" (o'z kompyuterining xususiyatlarini topish) |
| 60–72 | **Challenge** | `challenge.md`: "Qurilma Aukcioni" jamoaviy o'yini |
| 72–80 | **Yakun** | XP liga qoidalarini tushuntirish (10-slayd), jadvalga yozilish, uyga vazifa, "Bugun bitta yangi narsa o'rgandim: ..." |

## Mentor matni (asosiy fikrlar)
- *"Dasturchi — bu kompyuterga nima qilishni tushuntira oladigan odam. Kompyuter juda tez, lekin juda \"ahmoq\": u faqat aniq buyruqni tushunadi."*
- *"Bu yerda xato qilish — normal. Eng yaxshi dasturchilar kuniga yuzlab xato qiladi, faqat ularni tez tuzatadi."*
- *"Har bir darsda nimadir yasaymiz. Yil oxirida GitHub'da o'z loyihalaringiz portfeli bo'ladi."*

## Kurs xaritasi (o'quvchilarga ko'rsatish uchun)
IT olami → Algoritmlar → HTML → CSS → Git → JavaScript → Python → Telegram bot → Ma'lumotlar bazasi → **Demo Day**
