# 1-dars challenge: "Qurilma Aukcioni" 🔨

**Vaqt:** 12 daqiqa | **Format:** 3–4 kishilik jamoalar

## Qoidalar
1. Har bir jamoaga **1000 IT-tanga** beriladi (qog'ozga yoziladi).
2. Mentor "lot"larni birma-bir e'lon qiladi. Har bir lot — kompyuter qismi yoki IT fakti.
3. Jamoalar lotni sotib olish uchun narx taklif qiladi.
4. Sotib olgan jamoa lot haqidagi savolga javob berishi kerak:
   - to'g'ri javob → **2× narx** qaytadi;
   - noto'g'ri javob → tanga yo'qoladi.
5. Oxirida eng ko'p tangasi bor jamoa g'olib bo'ladi.

## Lotlar va savollar
| Lot | Savol | Javob |
|---|---|---|
| CPU | Oshxonada kim? | Oshpaz |
| RAM | Kompyuter o'chsa, undagi ma'lumot nima bo'ladi? | O'chib ketadi |
| SSD | HDD'dan asosiy afzalligi nima? | Tezroq, harakatlanuvchi qismi yo'q |
| Monitor | Kiritish yoki chiqarish qurilmasi? | Chiqarish |
| Sensorli ekran | Kiritish yoki chiqarish? | Ikkalasi ham |
| 1 GB | Necha MB? | 1024 MB |
| Front-end | Foydalanuvchi ko'radimi? | Ha |
| Back-end | Misol keltiring | Server, baza, login, to'lov |
| Telegram | Qaysi turdagi dasturchi uning botini yozadi? | Bot dasturchi / back-end |
| GPU | Nima uchun kerak? | Grafika, video, o'yin, AI |
