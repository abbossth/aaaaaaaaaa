# 2-dars slaydlari: Fayllar, papkalar, tezkor tugmalar

## 1-slayd
**Dasturchi kabi kompyuterda ishlash** ⌨️

## 2-slayd — Fayl va papka
📁 Papka = javon
📄 Fayl = kitob
🏷 Kengaytma = kitob turi (roman, darslik, jurnal)

## 3-slayd — Kengaytmalar
| Kengaytma | Nima? |
|---|---|
| `.txt` | Oddiy matn |
| `.html` | Veb-sahifa |
| `.css` | Sahifa dizayni |
| `.js` | JavaScript dastur |
| `.py` | Python dastur |
| `.png` `.jpg` | Rasm |
| `.zip` | Arxiv |

## 6-slayd — TOP-15 tezkor tugmalar
`Ctrl+C` nusxa · `Ctrl+V` qo'yish · `Ctrl+X` kesish · `Ctrl+Z` bekor qilish · `Ctrl+Y` qaytarish
`Ctrl+S` saqlash · `Ctrl+A` hammasini belgilash · `Ctrl+F` qidirish
`Alt+Tab` oynalar · `Win+E` Explorer · `Win+D` ish stoli · `F2` nomini o'zgartirish
`Ctrl+Shift+N` yangi papka · `Ctrl+T` yangi tab · `Ctrl+W` tabni yopish

## 7-slayd — Nega tez yozish muhim?
Dasturchi kuniga **minglab** belgi yozadi.
20 so'z/daqiqa → 1 sahifa = 15 daqiqa
60 so'z/daqiqa → 1 sahifa = 5 daqiqa
**O'n barmoq usuli = 3 barobar tezroq!**
