# 14-dars mentor eslatmasi

## Ko'p uchraydigan xatolar
| Xato | Yechim |
|---|---|
| `margin: 0 auto` ishlamaydi | Elementning `width`i yo'q yoki u inline element (`img`, `a`) |
| Doira emas, oval chiqadi | `width` va `height` teng emas |
| `background-image` ko'rinmaydi | Elementning balandligi yo'q yoki yo'l noto'g'ri (`url()` ichida CSS faylga nisbatan yo'l) |
| Padding qo'shilganda kartochka kattalashib ketadi | `box-sizing: border-box` |

## Maslahat
DevTools'dagi box model diagrammasini albatta ko'rsating: qiymatlarni to'g'ridan-to'g'ri o'sha yerda o'zgartirish mumkin. Bu "tajriba qilish" uchun eng yaxshi vosita.
