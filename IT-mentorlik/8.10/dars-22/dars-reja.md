# 22-dars. Figma → HTML/CSS: maketni kodga aylantirish

**Guruh:** 8.10 | **Turi:** 📘 Mavzu | **Davomiyligi:** 80 daqiqa

## Maqsad
- Figma maketidan o'lcham, rang, shrift va oraliqlarni o'qiydi (Inspect panel).
- Maketni bo'limlarga ajratib, semantik HTML skeletini tuzadi.
- Auto Layout → Flexbox, kartochkalar to'ri → Grid qilib o'giradi.
- CSS o'zgaruvchilari (`:root { --asosiy: ... }`) bilan ranglarni bir joyda saqlaydi.
- 21-darsdagi o'z maketini ishlaydigan, responsiv sahifaga aylantiradi.

## Dars rejasi
