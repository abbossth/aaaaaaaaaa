# 1-dars diagnostika testi (15 savol)

**HTML**
1. Eng katta sarlavha tegi? — `<h1>`
2. Havola tegi? — `<a href="...">`
3. Rasmdagi `alt` atributi nima uchun? — Rasm yuklanmasa matn chiqadi, ko'zi ojizlar va SEO uchun
4. Tartiblangan ro'yxat tegi? — `<ol>`
5. Semantik teglardan 3 tasini ayting. — `header`, `nav`, `main`, `section`, `article`, `footer`

**CSS**
6. Sinf (class) selektori qanday yoziladi? — `.nom`
7. `margin` va `padding` farqi? — margin tashqi, padding ichki bo'shliq
8. Elementlarni qatorga terish uchun qaysi CSS xossasi? — `display: flex`
9. Ekran kichik bo'lganda boshqa stil berish uchun nima ishlatiladi? — `@media` so'rovi
10. Rang yozishning 3 usuli? — nomi (`red`), HEX (`#ff0000`), `rgb(255,0,0)`

**JavaScript**
11. O'zgaruvchi e'lon qilish kalit so'zlari? — `let`, `const` (`var` eski)
12. Brauzer oynasida xabar chiqarish? — `alert()`
13. Konsolga chiqarish? — `console.log()`
14. `5 + "5"` natijasi? — `"55"`
15. Elementni id bo'yicha topish? — `document.getElementById("id")`

**Baholash:** 13–15 = kuchli, 8–12 = o'rta, 0–7 = takrorlash kerak.
