# 1-dars mentor eslatmasi

- **Diagnostikani baho uchun ishlatmang.** O'quvchilarga ayting: *"Bu imtihon emas, men sizga qanday yordam berishni bilishim uchun."*
- Natijalarni jadvalga yozing: bu **juftliklar tuzish** uchun kerak bo'ladi (kuchli + zaif).
- O'tgan yilgi bilimlar "unutilgan" bo'lishi normal. Ko'pchilik `flex` va `media`ni eslay olmaydi, 2–4-darslar aynan shu uchun.
- 8.2 o'quvchilari "biz buni bilamiz" deb zerikishi mumkin. Shuning uchun takrorlash darslari **musobaqa** shaklida (speed-run, Froggy, CSS Battle).
- GitHub akkaunt ochishda 13 yosh chegarasi bor. 8-sinf o'quvchilari odatda 13–14 yoshda. Kichikroq o'quvchi bo'lsa, ota-ona roziligi bilan yoki keyinroq oching.
