# 1-dars challenge: "Web Detektiv" 🕵️

**Vaqt:** 12 daqiqa | **Format:** juftliklar

Mentor ekranda savollarni birma-bir chiqaradi. Juftliklar javobni **F12 (DevTools)** yordamida topishi kerak. Kim birinchi to'g'ri javob bersa, ball oladi.

| № | Savol | Qanday topiladi |
|---|---|---|
| 1 | `kun.uz` sahifasining `<title>` i nima? | Elements yoki tab nomi |
| 2 | `google.com` logotipi qaysi formatda (png/svg/webp)? | Elements → logotip ustida sichqoncha o'ng tugma → Inspect |
| 3 | `youtube.com` sahifasi nechta JS fayl yuklaydi? (±5) | Network → JS filtri |
| 4 | `uzum.uz` qaysi asosiy shriftdan foydalanadi? | Elements → Computed → font-family |
| 5 | Istalgan saytdagi sarlavha matnini o'zgartiring va skrinshot qiling ("fake news" 😄) | Elements → matnga ikki marta bosish |
| 6 | `github.com` foni qaysi rang kodida? | Elements → body → Styles |

**Muhim xulosa (5-savoldan keyin):** *"DevTools'da o'zgartirilgan narsa faqat sizning ekraningizda o'zgaradi. Serverdagi haqiqiy sayt o'zgarmaydi. Shuning uchun internetdagi skrinshotlarga har doim ham ishonib bo'lmaydi!"*

**XP:** 1-o'rin +30, 2-o'rin +20, 3-o'rin +10. Har bir to'g'ri javob +2.
