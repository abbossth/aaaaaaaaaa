# Emmet cheat-sheet (VS Code)

| Yozing + Tab | Natija |
|---|---|
| `!` | HTML5 skelet |
| `h1{Matn}` | `<h1>Matn</h1>` |
| `p*3` | 3 ta paragraf |
| `ul>li*5` | 5 elementli ro'yxat |
| `ul>li*3{Element $}` | Element 1, Element 2, Element 3 |
| `.card` | `<div class="card"></div>` |
| `#main` | `<div id="main"></div>` |
| `section.about>h2+p` | class'li section, ichida h2 va p |
| `a[href=#]{Bosh sahifa}` | havola |
| `img[src=rasm.jpg alt=Rasm]` | rasm |
| `table>tr*3>td*4` | 3×4 jadval |
| `form>input:text+input:email+button{Yuborish}` | forma |
| `lorem20` | 20 so'zlik test matni |

**Formatlash:** `Shift+Alt+F` · **Qatorni nusxalash:** `Shift+Alt+↓` · **Ko'p kursor:** `Alt+Click`
