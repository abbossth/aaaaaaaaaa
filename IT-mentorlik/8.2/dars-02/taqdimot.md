# 2-dars slaydlari: HTML Speed-run ⚡

## 1-slayd
**HTML SPEED-RUN** 🏁 — kim eng tez va eng toza?

## 2-slayd — Emmet sehrlari
`!` + Tab → to'liq HTML skelet
`h1{Salom}` → `<h1>Salom</h1>`
`ul>li*3` → 3 elementli ro'yxat
`.card>h2+p` → class'li div ichida sarlavha va paragraf
`a[href=#]{Link}` → havola

## 3-slayd — Semantik skelet
```
header  → logo, sarlavha
nav     → menyu
main    → asosiy kontent
  section → bo'lim
  article → mustaqil maqola/kartochka
aside   → yon panel
footer  → pastki qism
```
