# 3-dars mentor eslatmasi

## Ko'p uchraydigan xatolar
| Xato | Yechim |
|---|---|
| `display: flex` bolaga (elementga) yoziladi | Flex **ota** (konteyner)ga yoziladi |
| `justify-content` va `align-items` chalkashtiriladi | "Justify — asosiy o'q, Align — ko'ndalang". `flex-direction: column` bo'lsa, ular joy almashadi |
| CSS fayl ulanmaydi | `href` dagi yo'l va fayl nomini tekshiring, `F12` → Console'da 404 xatosi ko'rinadi |
| Rasm kartochkadan chiqib ketadi | `img { width: 100%; }` |

## Maslahatlar
- Froggy saytiga maktab internetidan kirish mumkinligini oldindan tekshiring. Ishlamasa, offline versiya: GitHub'dan `thomaspark/flexboxfroggy` reposini yuklab olib, lokal ochish mumkin.
- Poyga vaqtida jim bo'lish shart emas, lekin javobni aytish taqiqlanadi.
- Grid Garden'ning oxirgi darajalari qiyin. Vaqt tugaganda, qolgan darajalarni uyda davom ettirishni tavsiya qiling.
