# 8.2 — Web Full-stack dasturlash: umumiy reja

**Guruh:** 8.2 (kompyuter savodxonligini tugatgan: Word, Excel, HTML, CSS va ozgina JS o'rgangan)
**Yo'nalish:** Web Full-stack dasturlash (8-sinf standarti asosida)
**Hajm:** 70 dars × 80 daqiqa, haftasiga 3 marta, 30-sentabrdan

## Guruhga xos yondashuv
- HTML/CSS **takrorlash + chuqurlashtirish** shaklida 9 darsda o'tiladi (speed-run, CSS Battle, Figma → kod).
- Asosiy vaqt **JavaScript → Python → Telegram bot → PostgreSQL → Django → DRF** ga ajratilgan. Bu rasmiy dasturni to'liq qamrab oladi.
- JQuery o'rniga zamonaviy vanilla JS va fetch API o'rgatiladi.
- **Yil davomidagi yakuniy loyiha:** jamoaviy **full-stack startap**: Django + DRF backend, JS frontend va deploy.

## Yil davomida o'quvchi yaratadigan loyihalar portfeli
1. Figma'dan kodga o'tkazilgan, AI yordamida yaxshilangan landing page (deploy qilingan)
2. JS ilovalar: To-Do, ob-havo, o'yin
3. Telegram bot + PostgreSQL
4. Django blog (CRUD + auth)
5. Full-stack startap MVP (Django + DRF + JS, internetda)
