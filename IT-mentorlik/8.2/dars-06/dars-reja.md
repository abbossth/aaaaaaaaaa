# 6-dars. CSS animatsiyalar, transform + Bootstrap tezkor

**Guruh:** 8.2 | **Turi:** 📘 Mavzu | **Davomiyligi:** 80 daqiqa

## Maqsad
- `transition`, `transform` (translate, scale, rotate) va `@keyframes` animatsiyalarini qo'llaydi.
- Hover effektlari va yuklanish animatsiyalarini yaratadi.
- Bootstrap'ni CDN orqali ulaydi va uning grid tizimi hamda tayyor komponentlaridan (navbar, card, button, modal) foydalanadi.
- "Qachon o'zim yozaman, qachon framework ishlataman" degan savolga javob bera oladi.
