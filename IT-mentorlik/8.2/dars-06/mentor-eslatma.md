# 6-dars mentor eslatmasi

- **Animatsiyada me'yor:** o'quvchilar hammasini aylantirib, sakratib yuborishga moyil. Qoida: "Animatsiya foydalanuvchiga yordam berishi kerak, uni chalg'itmasligi kerak."
- Bootstrap JS komponentlari (modal, navbar toggler) ishlamasa, sabab odatda `bootstrap.bundle.min.js` ulanmagani bo'ladi.
- Internet bo'lmasa, CDN ishlamaydi. Bootstrap fayllarini oldindan yuklab, lokal papkaga qo'yib qo'ying.
- Bootstrap'ni rasmiy dastur talab qiladi, lekin bu guruh uchun faqat "tanishuv" darajasida yetarli. Asosiy e'tibor — o'z CSS'ini yozish.
