# Prompt namunalari: AI bilan o'yin

## 1. Reja
```
Men 8-sinf o'quvchisiman, HTML, CSS va JavaScript asoslarini bilaman (DOM, eventlar, massivlar, setInterval).
Brauzerda ishlaydigan "Xotira kartalari" (memory cards) o'yinini yaratmoqchiman.
Hali kod yozma. Faqat reja tuz: qanday fayllar, qanday funksiyalar (nomi va vazifasi), qanday o'zgaruvchilar kerak.
```

## 2. Qism-qism
```
Rejaning 1-qadamini bajar: faqat index.html va style.css. 4x4 kartalar maydoni, CSS Grid bilan.
Kod sodda bo'lsin, har bir blokka o'zbekcha izoh yoz. Kutubxonalar ishlatma.
```

## 3. Tushuntirish
```
Quyidagi funksiyani 8-sinf o'quvchisiga qatorma-qator tushuntir:
[funksiya kodi]
```

## 4. Rezina o'rdak
```
Mening o'yinimda ikkita bir xil kartani ochganda ular yopilib qolyapti. Menga javobni aytma.
Savollar berib, xatoni o'zim topishimga yordam ber.
```
