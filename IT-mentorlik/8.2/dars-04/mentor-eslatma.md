# 4-dars mentor eslatmasi

## Ko'p uchraydigan xatolar
| Xato | Yechim |
|---|---|
| Media query ishlamaydi | Ko'pincha `viewport` meta yo'q yoki media query asosiy stildan **oldin** yozilgan (keyingi qoida ustun turadi) |
| Gorizontal scroll | Qat'iy `width: 1000px` yoki katta rasm. `max-width` ishlating |
| `@media (min-width: 768)` | Birlik (`px`) unutilgan |
| `min-width` va `max-width` aralash ishlatilib, chalkashlik | Bitta yondashuvni tanlang: mobile-first → faqat `min-width` |

## Maslahat
- Live Server'da sahifani telefonda ochish: kompyuter va telefon bitta Wi-Fi'da bo'lsa, `http://<kompyuter-IP>:5500` manzili orqali ochiladi (`ipconfig` bilan IP'ni toping). Bu o'quvchilarda katta "wow" effekt beradi.
