# 7-dars. Git va GitHub: repo, commit, push. Netlify/Vercel'ga deploy. SEO asoslari

**Guruh:** 8.2 | **Turi:** 📘 Mavzu | **Davomiyligi:** 80 daqiqa

## Maqsad
- Git nima uchun kerakligini (versiyalar tarixi, jamoaviy ish) tushunadi.
- `git init, add, commit, push` bilan loyihani GitHub'ga yuklaydi.
- Saytini **GitHub Pages** yoki **Netlify/Vercel** orqali internetga joylaydi va havolasini do'stlariga yubora oladi.
- SEO asoslarini biladi: `title`, `meta description`, semantik teglar, `alt`, Open Graph (Telegram'da havola ko'rinishi).

## Dars rejasi

| Vaqt | Bosqich | Nima qilinadi |
|---|---|---|
| 0–5 | **Hook** | *"Bugun dars oxirida saytingiz havolasini onangizga Telegram'da yuborasiz, u telefonidan ochadi."* Mentor oldindan deploy qilingan saytini ko'rsatadi. |
| 5–10 | **Takrorlash** | 6-dars testi |
| 10–22 | **Git va GitHub** | "O'yindagi save point" analogiyasi. Git Bash/VS Code terminalida: `config`, `init`, `add`, `commit`, `log`. GitHub'da repo yaratish, `remote add`, `push` |
| 22–45 | **Amaliyot 1** | Landing page'ni GitHub'ga push qilish |
| 45–60 | **Deploy** | GitHub Pages (Settings → Pages) yoki Netlify (repo'ni ulash / drag-and-drop). Havolani telefonda ochish 📱 |
| 60–72 | **SEO** | `title`, `meta description`, OG teglari. Telegram'ga havola yuborib, "preview" ko'rinishini tekshirish |
| 72–80 | **Yakun** | Hamma havolasini Telegram guruhga tashlaydi 🎉, XP, uyga vazifa |

## Baholash (XP)
- GitHub'ga push +10 · Sayt internetda +20 · SEO/OG teglari +10
