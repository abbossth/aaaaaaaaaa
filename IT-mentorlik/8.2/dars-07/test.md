# 7-dars tezkor test

1. O'zgarishlarni saqlash (commit) uchun avval nima qilinadi? — `git add`
2. GitHub'ga yuborish buyrug'i? — `git push`
3. Deploy nima? — Saytni internetga joylash (serverga yuklash)
4. Google natijalarida sayt tavsifi qaysi tegdan olinadi? — `<meta name="description">`
5. Telegram'dagi havola preview'si uchun qaysi teglar kerak? — Open Graph (`og:title`, `og:image`...)
6. Favicon nima? — Brauzer tabidagi kichik ikonka
