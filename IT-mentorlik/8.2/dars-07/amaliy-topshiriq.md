# 7-dars amaliy topshiriq

## 🟢 Oson (+10 XP)
1. `git config` bilan ism va email'ni sozlang.
2. Landing page papkangizda `git init` → `add` → `commit` qiling.
3. GitHub'da `landing` nomli **public** repo yarating va push qiling. Repo sahifasida fayllaringiz ko'rinishi kerak.

## 🟡 O'rta (+20 XP)
4. Saytni **GitHub Pages** yoki **Netlify** orqali deploy qiling.
5. Havolani telefoningizda oching va Telegram guruhga yuboring.

## 🔴 Qiyin (+10 XP)
6. `<head>` ga SEO va Open Graph teglarini qo'shing (`kod/seo-head.html`), favicon ham bo'lsin. O'zgarishni commit + push qiling va sayt avtomatik yangilanganini tekshiring.
7. Havolani Telegram'da yuboring: chiroyli preview (rasm + sarlavha) chiqdimi? Chiqmasa, @WebpageBot orqali Telegram keshini yangilang.
8. Repo'ga `README.md` qo'shing: sayt nomi, havolasi va skrinshoti.
