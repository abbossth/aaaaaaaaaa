# 12-dars challenge: "Tosh-qaychi-qog'oz" ✊✌️✋

**Vaqt:** 17 daqiqa | **Format:** juftlik

## Talablar
1. Foydalanuvchi `prompt` bilan tanlaydi: `tosh`, `qaychi` yoki `qog'oz`.
2. Kompyuter tasodifiy tanlaydi:
```js
const variantlar = ["tosh", "qaychi", "qog'oz"];
const komp = variantlar[Math.floor(Math.random() * 3)];
```
3. G'olib aniqlanadi va `alert` bilan chiqariladi: `Siz: tosh ✊ | Kompyuter: qaychi ✌️ → Siz yutdingiz! 🎉`
4. Noto'g'ri kiritilsa, xabar chiqsin (`toLowerCase()` va `trim()` bilan tozalang).
