# 17-dars mentor eslatmasi

## Ko'p uchraydigan xatolar
| Xato | Yechim |
|---|---|
| `Cannot read properties of null` | Element topilmadi: selektor noto'g'ri yoki `<script>` HTML'dan oldin ishladi (`defer` yoki body oxiri) |
| `querySelectorAll(...).style` → xato | NodeList — ro'yxat. `forEach` kerak |
| `querySelector("sarlavha")` (# siz) | CSS selektor qoidalari: id → `#`, class → `.` |
| `innerHTML +=` siklda → sekin va eventlar yo'qoladi | Avval satrga yig'ish yoki `append` |

## Maslahat
Hook'dagi "saytni pushti qilish" va "hamma rasmlar mushuk" trigi o'quvchilarga juda yoqadi 😄. Bu DOM kuchini birinchi daqiqadayoq ko'rsatadi.
