# 23-dars slaydlari: Mini loyiha 🚀

## 1-slayd
**Foydali interaktiv sayt · 3 kishi · deploy**

## 2-slayd — Variantlar
🧠 **Viktorina:** kategoriyalar, taymer, natija va rekordlar
🎬 **Kino katalogi:** qidiruv, janr filtri, sevimlilar (❤️), batafsil oyna
🍕 **Kafe menyusi:** kategoriyalar, savat, jami summa
📚 **Kitoblar kutubxonasi:** o'qilgan/o'qilmagan, reyting, izoh
🌍 **Mamlakatlar gidi:** bayroq, poytaxt, aholi, qidiruv (API bilan: restcountries.com)

## 3-slayd — Majburiy talablar
✅ Ma'lumot JS massivida yoki JSON faylda (kamida 10 ta element)
✅ Render funksiyasi (massivdan DOM)
✅ Kamida 2 ta interaktiv funksiya (qidiruv, filtr, savat, sevimlilar...)
✅ `localStorage` · ✅ Responsiv · ✅ Deploy

## 4-slayd — Fayl tuzilishi
```
loyiha/
├── index.html
├── style.css
├── data.js      ← ma'lumotlar (1-a'zo)
├── render.js    ← chizish funksiyalari (2-a'zo)
└── app.js       ← eventlar, localStorage (3-a'zo)
```
Har kim o'z faylida → konfliktlar kam!
