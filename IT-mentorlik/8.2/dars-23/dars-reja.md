# 23-dars. 🚀 Mini loyiha: jamoaviy interaktiv sayt (quiz / kino katalogi) + deploy

**Guruh:** 8.2 | **Turi:** 🚀 Loyiha | **Davomiyligi:** 80 daqiqa

## Maqsad
- 1-modul (HTML/CSS) va 2-modul (JS) bilimlarini **foydali** ilovada birlashtirish.
- Jamoada GitHub bilan ishlash: bitta repo, har kim o'z branch'i/fayli, pull/push.
- Ma'lumotni JS massivida (yoki JSON faylda) saqlab, undan interfeys chizish.
- Loyihani deploy qilish va taqdim etishga tayyorlash (24-dars Demo).

## Dars rejasi

| Vaqt | Bosqich | Nima qilinadi |
|---|---|---|
| 0–5 | **Brifing** | Loyiha variantlari, talablar, baholash |
| 5–15 | **Reja** | Jamoa: variant tanlash, qog'ozda maket (5 daqiqa), vazifalarni taqsimlash, GitHub repo |
| 15–70 | **Qurish** | Har 20 daqiqada "sync": `git pull` → `push`. Mentor jamoalarni aylanadi |
| 70–80 | **Deploy va tekshiruv** | Netlify/GitHub Pages, telefonda sinash. Demo 24-darsda |
