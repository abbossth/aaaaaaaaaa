# 18-dars tezkor test

2. Input'ga har bir harf yozilganda qaysi event? — `input`
3. Forma yuborilganda sahifa yangilanmasligi uchun? — `e.preventDefault()`
4. Bosilgan klaviatura tugmasi qayerda? — `e.key`
5. Hodisa sodir bo'lgan element? — `e.target`
6. Event delegation nima? — Ko'p bolalar o'rniga ota elementga bitta listener qo'yish
7. `data-kategoriya` atributini JS'da o'qish? — `el.dataset.kategoriya`
