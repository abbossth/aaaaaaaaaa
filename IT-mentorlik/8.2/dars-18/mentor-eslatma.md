# 18-dars mentor eslatmasi

## Ko'p uchraydigan xatolar
| Xato | Yechim |
|---|---|
| `addEventListener("click", f())` — funksiya darhol chaqiriladi | Qavssiz: `f` yoki `() => f()` |
| `onclick` va `addEventListener` aralash | Bitta usul: `addEventListener` |
| Dinamik qo'shilgan elementlarda listener ishlamaydi | Event delegation |
| AudioContext ovoz chiqarmaydi | Brauzer foydalanuvchi harakatisiz ovozni bloklaydi. Birinchi click/keydown'dan keyin ishlaydi |
