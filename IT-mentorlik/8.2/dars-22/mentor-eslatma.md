# 22-dars mentor eslatmasi

- Jamoalarni oldindan muvozanatli tuzing.
- Hakaton paytida **yechim bermang**, faqat yo'naltiruvchi savollar bering: "Console'da qanday xato bor?", "Bu o'zgaruvchi hozir nimaga teng?"
- Jamoalar 3 kishi bo'lib bitta kodda ishlashda qiynaladi. VS Code **Live Share** kengaytmasi yoki "bitta kompyuter + navbat bilan klaviatura" (mob programming) usullarini tavsiya qiling.
- 35-daqiqada "Hozir ishlaydigan narsangiz bormi?" deb so'rang. Yo'q bo'lsa — funksiyalarni qisqartirishni maslahat bering.
