# 20-dars tezkor test

1. API nima? — Dasturlar o'zaro ma'lumot almashadigan interfeys
2. `fetch` nima qaytaradi? — Promise (Response'ga aylanadigan)
3. `await` qaysi funksiya ichida ishlatiladi? — `async` funksiya ichida
4. JSON javobni obyektga aylantirish? — `await res.json()`
5. Server 404 qaytarsa, `fetch` xato chiqaradimi? — Yo'q! `res.ok` ni tekshirish kerak
6. Tarmoq xatolarini ushlash? — `try/catch`
