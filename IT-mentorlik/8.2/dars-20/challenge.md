# 20-dars challenge: "API safari" 🦁

**Vaqt:** 16 daqiqa | **Format:** juftlik

Har bir API'dan ma'lumot olib, sahifada chiroyli ko'rsating. Har bir ishlaydigan qism +5 XP:

| № | API | Vazifa |
|---|---|---|
| 1 | `https://api.github.com/users/<username>` | GitHub profilingiz: avatar, ism, repolar soni |
| 2 | `https://dog.ceo/api/breeds/image/random` | "Yangi it" tugmasi: tasodifiy it rasmi 🐶 |
| 3 | `https://api.adviceslip.com/advice` | Kunlik maslahat (inglizcha) |
| 4 | `https://cbu.uz/uz/arkhiv-kursov-valyut/json/` | Dollar, yevro, rubl kursi (Markaziy bank) |
| 5 | `https://pokeapi.co/api/v2/pokemon/pikachu` | Pokemon kartochkasi: rasm, nom, turlari |

**XP:** eng ko'p ishlaydigan qismlar: 🥇 +20 · 🥈 +10 · 🥉 +5

Eslatma: ba'zi API'lar CORS yoki tarmoq sababli ishlamasligi mumkin. Bu ham saboq: Console'dagi xatoni o'qing!
