## ✅ Yaxshi prompt
```
Sen tajribali front-end dasturchi va o'qituvchisan.

Vazifa: "Oqtepa Lavash" uslubidagi xayoliy fast-food kafe uchun bir sahifali landing page yarat.

Kontekst: men 8-sinf o'quvchisiman, HTML va CSS'ni bilaman, JavaScript'ni endi o'rganyapman.

Format:
- bitta index.html va bitta style.css
- kod ichida qisqa izohlar o'zbek tilida
- bo'limlar: header (logo + menyu), hero, menyu kartochkalari (6 ta taom), "biz haqimizda", aloqa formasi, footer

Cheklovlar:
- faqat semantik teglar (header, nav, main, section, footer)
- Flexbox va Grid ishlat, position: absolute ishlatma
- responsiv: telefonda kartochkalar 1 ustun, kompyuterda 3 ustun
- 2 ta asosiy rang, Google Fonts'dan Poppins
- rasmlar uchun https://picsum.photos ishlat
- JavaScript ishlatma
```
