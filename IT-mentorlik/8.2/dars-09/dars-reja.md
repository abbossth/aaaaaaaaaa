# 9-dars. 🏆 CSS Battle musobaqasi (1-modul yakuni)

**Guruh:** 8.2 | **Turi:** 🏆 Challenge | **Davomiyligi:** 80 daqiqa

## Maqsad
- CSS bilimlarini (o'lcham, rang, position, border-radius, box-shadow, flex/grid, pseudo-elementlar) "rasmni kod bilan chizish" orqali mustahkamlash.
- Minimal kod bilan maksimal aniqlikka erishishni o'rganish.
- 1-modul (Front-end) yakuni: XP liga natijalari.

## Dars rejasi

| Vaqt | Bosqich | Nima qilinadi |
|---|---|---|
| 0–5 | **Hook** | cssbattle.dev'dagi eng yaxshi yechimlar: 20–30 belgilik kod bilan chizilgan murakkab rasmlar. *"Bugun siz rassomsiz, mo'yqalamingiz esa — CSS."* |
| 5–15 | **Mini-dars** | CSS Battle qoidalari: 400×300 maydon, rasmga 100% moslik, kod qisqaligi. Foydali usullar: `position: absolute`, `border-radius: 50%`, `box-shadow` bilan nusxa yaratish, `::before/::after`, `margin: auto` |
| 15–30 | **Isinish** | Hamma birga 1-target (Simply Square) → mentor bilan qadamma-qadam |
| 30–70 | **Battle** | `challenge.md` — 4 raund |
| 70–80 | **Yakun** | G'oliblar, 1-modul XP natijalari, TOP-5, badge'lar. Keyingi darsdan — JavaScript! |

## Baholash (XP)
- Har bir raundda 100% moslik +10
- Raund g'oliblari +15/+10/+5
- Umumiy chempion +30 va 🎨 "CSS Master" badge
