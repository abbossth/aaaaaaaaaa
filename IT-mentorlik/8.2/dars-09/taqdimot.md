# 9-dars slaydlari: CSS Battle

## 1-slayd
🎨⚔️ **CSS BATTLE** — rasmni kod bilan chiz!

## 2-slayd — Qoidalar
- Maydon: 400 × 300 px
- Maqsad: rasmga **100%** moslik
- Qo'shimcha ball: kod qanchalik qisqa bo'lsa, shuncha yaxshi

## 3-slayd — Asosiy qurollar 🗡
```css
body { background: #62374e; margin: 0; }
div { width: 200px; height: 200px; background: #fdc57b; }
```
`border-radius: 50%` → doira
`position: absolute; top: 50px; left: 50px;` → aniq joy
`margin: 50px auto;` → gorizontal markaz

## 4-slayd — Maxfiy qurollar 🥷
`box-shadow: 100px 0 #fdc57b;` → elementning nusxasi!
`::before` / `::after` → bitta div'dan 3 ta shakl
`display: grid; place-items: center;` → mukammal markaz
