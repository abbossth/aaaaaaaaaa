# 9-dars amaliy topshiriq

Asosiy amaliyot — CSS Battle (`challenge.md`). Tez tugatganlar uchun:

## 🟢 Oson (+5 XP)
CSS bilan **O'zbekiston bayrog'ini** chizing (3 ta rangli yo'lak va 2 ta oq chiziq, yarim oy va yulduzlarsiz).

## 🟡 O'rta (+10 XP)
Bayroqqa yarim oyni qo'shing (ikkita doira usuli: oq doira ustiga ko'k doira biroz siljitib qo'yiladi).

## 🔴 Qiyin (+20 XP)
Faqat CSS bilan emoji chizing: 😀 yoki 🐸 (doiralar, `border-radius`, `::before/::after`). Bitta div'dan foydalanganga +10 bonus.
