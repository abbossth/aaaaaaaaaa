# 16-dars mentor eslatmasi

## Ko'p uchraydigan xatolar
| Xato | Yechim |
|---|---|
| `localStorage.setItem("x", obj)` → `"[object Object]"` saqlanadi | `JSON.stringify` |
| `JSON.parse(null)` → `null`, keyin `.push` xatosi | `JSON.parse(...) \|\| []` |
| Arrow funksiyali metodda `this` ishlamaydi | Obyekt metodlari uchun qisqa sintaksis: `salom() {}` |
| `obj.kalit nomi` (probelli kalit) | `obj["kalit nomi"]` |

## Maslahat
Keyingi 3 darsda DOM + eventlar + localStorage birlashib, "To-Do ilova" (19-dars) paydo bo'ladi. Bugungi kontaktlar mashqi uning "ma'lumot qatlami".
