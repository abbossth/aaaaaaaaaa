# 16-dars tezkor test

1. Obyekt xossasini o'qishning 2 usuli? — `obj.key` va `obj["key"]`
2. Barcha kalitlar ro'yxati? — `Object.keys(obj)`
3. `const { ism } = user` nima qiladi? — user.ism ni `ism` o'zgaruvchisiga oladi (destructuring)
4. Obyektni JSON satrga aylantirish? — `JSON.stringify()`
5. JSON satrni obyektga? — `JSON.parse()`
6. `localStorage` ga obyekt saqlash uchun avval nima qilish kerak? — `JSON.stringify` qilish
