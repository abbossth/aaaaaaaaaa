# 33-dars mentor eslatmasi

- Batafsil material: `../../9.2/dars-20/` (taqdimot, test, mentor eslatmalari).
- Maktab tarmog'ida `api.telegram.org` bloklangan bo'lishi mumkin — dars oldidan tekshiring. Kerak bo'lsa telefon hotspot'i.
- Eng ko'p xato: venv faollashtirilmagan (`ModuleNotFoundError: aiogram`), `.env` noto'g'ri joyda, token oxirida bo'sh joy.
- Bitta token bilan 2 ta joyda bot ishga tushsa: `TelegramConflictError`. Har kim o'z tokenidan foydalansin.
- Windows PowerShell'da `activate` ishlamasa: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.
