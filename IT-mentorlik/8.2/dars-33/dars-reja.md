# 33-dars. Telegram bot: BotFather, aiogram 3, echo bot

**Guruh:** 8.2 | **Turi:** 📘 Mavzu | **Davomiyligi:** 80 daqiqa

## Maqsad
- Telegram bot qanday ishlashini tushunadi: foydalanuvchi → Telegram serveri → bizning kod (polling).
- @BotFather orqali bot yaratadi va token oladi. Tokenni `.env` faylda saqlaydi.
- `venv` yaratadi, `pip install aiogram python-dotenv` qiladi.
- Aiogram 3: `Bot`, `Dispatcher`, handler, filtr (`CommandStart`, `Command`, `F.text`).
- `/start`, `/help` va echo bot yozib, telefonda sinaydi 📱
