# 5-dars. Figma → HTML/CSS: maketdan kodga

**Guruh:** 8.2 | **Turi:** 📘 Mavzu | **Davomiyligi:** 80 daqiqa

## Maqsad
- Figma interfeysini biladi: frame, layer, auto layout, Inspect/Dev Mode.
- Maketdan o'lcham, rang, shrift va oraliqlarni (spacing) o'qiy oladi.
- Oddiy landing page maketini chizadi va uni HTML/CSS'ga aylantiradi.
- Dizayner va dasturchi qanday hamkorlik qilishini tushunadi.

## Dars rejasi

| Vaqt | Bosqich | Nima qilinadi |
|---|---|---|
| 0–5 | **Hook** | Figma Community'dan chiroyli landing page maketini ochish. *"Real kompaniyalarda dasturchi mana shunday maket oladi va uni 1:1 kodga aylantiradi. Maketdan 1 pikselga farq ham 'bug' hisoblanadi."* |
| 5–10 | **Takrorlash** | 4-dars testi |
| 10–25 | **Figma asoslari** | Jonli: frame (Desktop 1440), rectangle, text, image, auto layout (bu Flexbox'ning o'zi!), ranglar va shrift uslublari. Inspect paneli: CSS kodini ko'rish |
| 25–45 | **Amaliyot 1** | O'quvchilar o'z landing page maketini chizadi (`amaliy-topshiriq.md`, 1-qism) |
| 45–70 | **Amaliyot 2** | Maketni kodga aylantirish (2-qism) |
| 70–78 | **Challenge** | `challenge.md`: "Pixel Perfect" |
| 78–80 | **Yakun** | XP, uyga vazifa |

## Asosiy g'oya (doskaga)
**Figma Auto Layout = CSS Flexbox**
| Figma | CSS |
|---|---|
| Direction: horizontal/vertical | `flex-direction: row/column` |
| Spacing between items | `gap` |
| Padding | `padding` |
| Alignment | `justify-content`, `align-items` |
| Fill container | `flex: 1` / `width: 100%` |
| Hug contents | `width: fit-content` |
