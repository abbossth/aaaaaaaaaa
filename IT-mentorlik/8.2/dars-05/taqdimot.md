# 5-dars slaydlari: Figma → Kod

## 1-slayd
🎨 **Dizayner chizadi → 👨‍💻 Dasturchi quradi**

## 2-slayd — Figma nima?
Brauzerda ishlaydigan dizayn vositasi. Butun jamoa bir faylda birga ishlaydi.
Airbnb, Uber, Uzum, Google dizaynerlari foydalanadi.

## 3-slayd — Asosiy tushunchalar
**Frame** — ekran (Desktop 1440, iPhone 390)
**Layer** — har bir element
**Auto Layout** — avtomatik joylashuv (Flexbox'ning o'zi!)
**Component** — qayta ishlatiladigan element (tugma, kartochka)

## 4-slayd — Dasturchi uchun Inspect
Elementni tanlang → o'ng panel → **Inspect** (yoki Dev Mode) → tayyor CSS:
```css
width: 320px; padding: 24px; gap: 16px;
border-radius: 12px; background: #FFFFFF;
font-family: Inter; font-size: 18px;
```

## 5-slayd — Landing page tuzilmasi
1. Header (logo + menyu)
2. Hero (katta sarlavha + tugma + rasm)
3. Features (3 ta afzallik)
4. CTA (harakatga chaqiriq)
5. Footer

## 6-slayd — Dizayn qoidalari
🎨 Ko'pi bilan 2–3 asosiy rang · 🔤 1–2 ta shrift · 📏 Oraliqlar 8 ga karrali (8, 16, 24, 32) · ⬜ Bo'sh joydan qo'rqmang
