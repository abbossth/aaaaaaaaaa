# 5-dars amaliy topshiriq

## 1-qism: Maket (Figma, 20 daqiqa) (+10 XP)
Mavzuni tanlang: **o'z sevimli hobbingiz**, **xayoliy kafe** yoki **maktab IT to'garagi**.
Desktop frame (1440 × istalgan balandlik) ichida:
- Header: logo + 3 ta menyu
- Hero: sarlavha, qisqa matn, tugma, rasm (Unsplash plagini yoki istalgan rasm)
- Features: 3 ta kartochka (Auto Layout bilan!)
- Footer

Qoidalar: 2–3 rang, bitta shrift (Google Fonts'dan: Inter, Montserrat, Poppins).

## 2-qism: Kod (25 daqiqa)
### 🟢 Oson (+5 XP)
Header va Hero bo'limlarini kodga aylantiring. Rang va shriftlar maketdagidek bo'lsin (Google Fonts'ni ulang).
### 🟡 O'rta (+10 XP)
Features kartochkalarini Flexbox yoki Grid bilan, maketdagi `gap` va `padding` qiymatlari bilan quring.
### 🔴 Qiyin (+20 XP)
Butun sahifa + responsiv (telefonda kartochkalar ustma-ust). Figma'da Mobile (390) frame ham chizib, unga moslang.

Namuna: `kod/landing.html`
