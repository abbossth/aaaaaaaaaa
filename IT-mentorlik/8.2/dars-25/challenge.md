# 25-dars challenge: "JS'dan Python'ga tarjimon" 🔄

**Vaqt:** 10 daqiqa | **Format:** juftlik

Quyidagi JS kodlarni Python'ga "tarjima" qiling. Har biri ishlashi kerak!

```js
// 1
const ism = prompt("Ismingiz?");
console.log(`Salom, ${ism}!`);

// 2
const a = Number(prompt("a:"));
const b = Number(prompt("b:"));
console.log("Yig'indi:", a + b);

// 3
const narx = 150000;
const chegirma = 0.2;
console.log(`Yangi narx: ${narx * (1 - chegirma)} so'm`);

// 4
let yosh = 14;
yosh += 1;
console.log(yosh, typeof yosh);
```
