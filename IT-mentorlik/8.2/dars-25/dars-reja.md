# 25-dars. Back-end nima? Python o'rnatish, o'zgaruvchilar, input/print

**Guruh:** 8.2 | **Turi:** 📘 Mavzu | **Davomiyligi:** 80 daqiqa

## Maqsad
- Back-end nima ekanini va front-end bilan qanday "gaplashishini" tushunadi (client-server, API — 20-darsda ishlatgan API'lar aynan back-end!).
- Python'ni o'rnatadi, VS Code'da sozlaydi, terminaldan dastur ishga tushiradi.
- O'zgaruvchilar va turlar (`int, float, str, bool`), `input()`, `print()`, f-string bilan ishlaydi.
- JS va Python sintaksisini taqqoslaydi (ular o'xshash, lekin farqlari bor!).
