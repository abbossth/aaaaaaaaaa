## 4-slayd — JS va Python
| JavaScript | Python |
|---|---|
| `let ism = "Aziz";` | `ism = "Aziz"` |
| `console.log(ism);` | `print(ism)` |
| `` `Salom, ${ism}` `` | `f"Salom, {ism}"` |
| `prompt("Ism?")` | `input("Ism? ")` |
| `Number("5")` | `int("5")` |
| `if (x > 5) { ... }` | `if x > 5:` + **chekinish (4 probel)** |
| `true / false / null` | `True / False / None` |
| `// izoh` | `# izoh` |
**Python'da `;` va `{}` yo'q — chekinish (indent) muhim!**
