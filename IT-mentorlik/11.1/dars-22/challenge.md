# 22-dars challenge: "Kanban o'yini" 🏭

**Vaqt:** 25 daqiqa | **Format:** jamoalar (4–5 kishi) | **Kerak:** stikerlar, qog'ozlar, qalam

## Vazifa: "Tabriknoma fabrikasi"
Har bir tabriknoma 4 bosqichdan o'tadi (har bir bosqichga bitta odam):
1. ✂️ Qog'ozni ikkiga buklash
2. ✏️ Chegara chizish
3. 🌸 Rasm chizish (gul, yulduz...)
4. ✍️ "Tabriklayman!" deb yozish → **Done**

## 1-raund (5 daqiqa): WIP limitsiz
Har bir bosqich imkon qadar tez ishlaydi va ishni keyingisiga "uloqtiradi".

## 2-raund (5 daqiqa): WIP limit = 2
Har bir bosqich oldida ko'pi bilan 2 ta ish turishi mumkin. Joy bo'lmasa — **kutasiz** (yoki qo'shningizga yordam berasiz!).

## Tahlil (10 daqiqa)
| | 1-raund | 2-raund |
|---|---|---|
| Nechta tabriknoma **Done**? | | |
| Nechtasi "jarayonda" qoldi? | | |
| Eng sekin bosqich (bottleneck)? | | |
| Birinchi tabriknoma necha soniyada tayyor bo'ldi (lead time)? | | |

**Xulosa:** WIP limit bilan "jarayonda qolib ketgan" ish kamayadi, tor joy ko'rinadi, jamoa bir-biriga yordam beradi.
**XP:** ishtirok +10 · eng ko'p "Done" (2-raundda) jamoasi +10
