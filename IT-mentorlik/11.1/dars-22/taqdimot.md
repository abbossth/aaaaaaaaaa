# 22-dars slaydlari: Agile, Scrum, Kanban

## 1-slayd
🔁 **Kichik qadamlar · tez feedback · doimiy yaxshilash**

## 2-slayd — Agile manifesti (2001)
**Afzal ko'ramiz:**
👥 Odamlar va muloqotni → jarayon va vositalardan
💻 Ishlaydigan dasturni → keng qamrovli hujjatlardan
🤝 Mijoz bilan hamkorlikni → shartnoma muhokamasidan
🔄 O'zgarishga javob berishni → rejaga qat'iy amal qilishdan

## 3-slayd — Scrum sxemasi
```
Product Backlog ──▶ Sprint Planning ──▶ Sprint Backlog
   (hamma g'oyalar,                      │
    ustuvorlik bo'yicha)                 ▼
                              ┌── Sprint (1–2 hafta) ──┐
                              │  Daily Scrum (har kun)  │
                              └──────────┬─────────────┘
                                         ▼
                        Increment (ishlaydigan versiya)
                              Sprint Review → Retrospective → 🔁
```

## 4-slayd — Scrum rollari
👑 **Product Owner:** NIMA qilinadi (backlog, ustuvorlik)
🧭 **Scrum Master:** jarayon ishlashini ta'minlaydi, to'siqlarni olib tashlaydi
👩‍💻 **Developers:** QANDAY qilinadi (qurish)

## 5-slayd — Daily Scrum (15 daqiqa, tik turib!)
1. Kecha nima qildim?
2. Bugun nima qilaman?
3. Menga nima to'sqinlik qilyapti?

## 6-slayd — Definition of Done (DoD) ✅
"Tayyor" = ishlaydi + kod review'dan o'tgan + testlar yashil + main'ga merge qilingan + telefonda tekshirilgan

## 7-slayd — Kanban
```
│ To Do │ In Progress (WIP ≤ 3) │ Review (WIP ≤ 2) │ Done │
```
**WIP limit** — bir vaqtda nechta ish "jarayonda" bo'lishi mumkin. Kamroq boshla — ko'proq tugat!

## 8-slayd — Scrum vs Kanban
| | Scrum | Kanban |
|---|---|---|
| Ritm | Sprintlar (1–2 hafta) | Uzluksiz oqim |
| Rollar | PO, SM, Dev | Majburiy emas |
| O'zgarish | Sprint ichida — yo'q | Istalgan vaqtda |
| Asosiy metrika | Velocity | Cycle time |
**Bizda:** 🔀 **Scrumban** — sprintlar + Kanban board + WIP limit
