# 2-dars slaydlari: SDLC

## 1-slayd
**Mijoz nima so'radi vs biz nima qurdik** 🌳🪢

## 2-slayd — SDLC = Software Development Life Cycle
1️⃣ Talab → 2️⃣ Dizayn → 3️⃣ Kod → 4️⃣ Test → 5️⃣ Deploy → 6️⃣ Monitoring → 🔁

## 3-slayd — Har bir bosqich natijasi
Talab → User stories
Dizayn → Figma + arxitektura
Kod → Git repo, PR
Test → testlar, bug'lar
Deploy → release v1.0
Monitoring → loglar, alertlar

## 4-slayd — User story formati
> **Men** [kim] **sifatida**, [nima] **qilishni xohlayman**, **toki** [nima uchun].

Misol: *"Men o'quvchi sifatida tushlikni oldindan buyurtma qilmoqchiman, toki navbatda turmayman."*

## 5-slayd — Waterfall 💧
Talab → Dizayn → Kod → Test → Deploy (bir marta, ketma-ket)
✅ Aniq reja · ❌ Xato oxirida topiladi · ❌ O'zgarishga moslashmaydi

## 6-slayd — Agile 🔁
Kichik sikllar (sprint: 1–2 hafta). Har bir sprint oxirida ishlaydigan natija.
✅ Tez feedback · ✅ O'zgarishga tayyor · ❌ Intizom talab qiladi

## 7-slayd — Xatoni tuzatish narxi
Talab bosqichida: 1$ · Dizayn: 5$ · Kod: 10$ · Test: 20$ · **Production'da: 100$+**
(Boehm qoidasi, taxminiy nisbat)
