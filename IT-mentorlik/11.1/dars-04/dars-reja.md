# 4-dars. GitHub: Issues, Projects, jamoaviy ish

**Guruh:** 11.1 | **Turi:** 📘 Mavzu | **Davomiyligi:** 80 daqiqa
**Qo'llanma:** I bob, "Git/GitHub... Issues/Projects bilan vazifa boshqaruvi"

## Maqsad
- GitHub Issues orqali vazifa va bug'larni to'g'ri yozadi: sarlavha, tavsif, qadamlar, label, assignee, milestone.
- GitHub Projects (Kanban board) da jamoa ishini tashkil etadi.
- `git pull`, `fetch`, `clone` va remote tushunchalarini hamda "push rejected" sababini tushunadi.
- Commit va PR'ni issue bilan bog'laydi (`Closes #3`).

## Dars rejasi

| Vaqt | Bosqich | Nima qilinadi |
|---|---|---|
| 0–5 | **Hook** | Real open-source loyihaning (masalan, `facebook/react`) Issues bo'limini ochish: 800+ ochiq issue, label'lar, "good first issue". *"Dunyodagi minglab dasturchi mana shu yerda bir-biri bilan ishlaydi. Siz ham ular kabi ishlaysiz."* |
| 5–10 | **Takrorlash** | 3-dars testi + "push rejected" muammosini muhokama qilish |
| 10–25 | **Yangi mavzu** | Local vs remote, `fetch`/`pull`/`push`. Yaxshi issue anatomiyasi. Label'lar (bug, feature, docs, good first issue). Projects board: Backlog → To Do → In Progress → Review → Done |
| 25–55 | **Amaliyot** | `amaliy-topshiriq.md`: jamoa reposida board va issue'lar |
| 55–72 | **Challenge** | `challenge.md`: "Bug report poygasi" |
| 72–80 | **Yakun** | Har bir jamoa board'ini ko'rsatadi, XP, uyga vazifa |

## Baholash (XP)
- Board sozlangan +10 · Har bir sifatli issue +3 (max 15) · Challenge +20/+10/+5
