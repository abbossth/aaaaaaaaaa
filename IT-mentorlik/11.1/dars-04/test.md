# 4-dars tezkor test

1. `git pull` qaysi ikki buyruqning birikmasi? — `git fetch` + `git merge`
2. "Push rejected" bo'lsa nima qilinadi? — Avval `git pull`, keyin `git push`
3. Yaxshi bug report'da nimalar bo'lishi kerak? — Takrorlash qadamlari, kutilgan va haqiqiy natija, muhit, skrinshot
4. Issue commit orqali qanday avtomatik yopiladi? — Xabarda `Closes #N` / `Fixes #N`
5. Kanban board'ning odatiy ustunlari? — Backlog, To Do, In Progress, Review, Done
