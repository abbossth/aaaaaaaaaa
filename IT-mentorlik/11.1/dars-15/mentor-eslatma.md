# 15-dars mentor eslatmasi

- jsonplaceholder'da POST/PUT/DELETE **soxta**: javob to'g'ri keladi, lekin ma'lumot aslida o'zgarmaydi. Buni oldindan aytib qo'ying, aks holda o'quvchilar "nega o'chirilgan post yana bor?" deb hayron bo'ladi.
- dummyjson'dagi test foydalanuvchi ma'lumotlari (`emilys`/`emilyspass`) o'zgarishi mumkin. Dars oldidan dummyjson.com/docs/auth'da tekshiring.
- Postman Desktop maktab kompyuterlarida o'rnatilmagan bo'lsa: VS Code **Thunder Client** yoki brauzerdagi Postman Web.
- Keyingi dars (16) — Express bilan o'z REST API'mizni yozamiz. Bugungi "REST arxitektori" jadvali o'sha yerda kerak bo'ladi.
