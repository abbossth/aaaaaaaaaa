# 17-dars mentor eslatmasi

- `bcrypt` native modul: ba'zi Windows kompyuterlarda o'rnatishda muammo bo'lishi mumkin. Muqobil: `bcryptjs` (sof JS, API bir xil).
- Bu dars hajmli. Agar vaqt yetmasa, React qismini uyga vazifaga o'tkazing, lekin auth API va CORS darsda albatta bajarilsin.
- `localStorage` da token saqlash XSS'ga zaif. Kuchli o'quvchilarga httpOnly cookie usulini aytib o'ting. Hozircha o'rganish uchun localStorage yetarli.
- Keyingi dars (18) — startap haftasi. Jamoalar muammolar ro'yxatini tayyorlab kelishini eslating.
