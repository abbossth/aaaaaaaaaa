# 11.1 — Professional IT Development: umumiy reja

**Guruh:** 11.1. O'quvchilar HTML, CSS, JS, Bootstrap, Git/GitHub va terminalni biladi, ozgina React asoslarini ham o'rgangan. **Python'ni bilmaydi.**
**Yo'nalish:** Professional IT Development (11-sinf standarti asosida)
**Hajm:** 70 dars × 80 daqiqa, haftasiga 3 marta, 30-sentabrdan
**Asosiy manba:** "Professional IT development" o'quv qo'llanmasi (TATU, 2025)

## Guruhga xos yondashuv
- **Kurs = startap inkubator.** Birinchi haftada 3–4 kishilik jamoalar tuziladi. Har bir jamoa yil davomida o'z **startap MVP'sini** quradi. Rasmiy dasturdagi barcha mavzular (Git, Clean Code, Docker, CI/CD, bulut, freelance, Agile) aynan shu loyiha ustida qo'llaniladi.
- Qo'llanmadagi kod misollari asosan Python'da. Bu guruh **JS/Node/React**'ni bilgani uchun barcha misollar **JavaScript/Node.js**'ga moslashtirilgan. Kerakli joylarda Python varianti ham qisqacha ko'rsatiladi.
- Rasmiy dasturdagi 51 dars 70 darsga kengaytirilgan. Qo'shimcha darslar Node.js/Express asoslari, AI bilan mahsulot yaratish, sprintlar, hakatonlar va karyera tayyorgarligiga ajratilgan.
- **Sprint ritmi:** har bir bobdan keyin 1–2 ta sprint darsi bor. Jamoalar Scrum bo'yicha ishlaydi: sprint planning → daily stand-up → review → retro.

## Yil yakunida o'quvchida bo'ladigan narsalar
1. Internetda HTTPS bilan ishlaydigan startap MVP (React + Node/Express + DB, Docker, CI/CD)
2. Optimallashtirilgan GitHub profil + portfolio va case study
3. Freelance platformadagi tayyor profil (Upwork/Fiverr/Kwork)
4. 3 daqiqalik pitch va pitch deck
5. Rezyume va texnik intervyu tajribasi
