# 🐧 Linux cheat-sheet

| Buyruq | Nima qiladi |
|---|---|
| `pwd` | Hozirgi papka |
| `ls -la` | Barcha fayllar (yashirinlar ham, batafsil) |
| `cd papka` / `cd ..` / `cd ~` / `cd -` | Papkaga kirish / yuqoriga / uyga / oldingi papkaga |
| `mkdir -p a/b/c` | Ichma-ich papkalar |
| `touch f.txt` | Bo'sh fayl |
| `cp -r a b` | Nusxalash (papka bilan) |
| `mv a b` | Ko'chirish / nomini o'zgartirish |
| `rm f` / `rm -r papka` | O'chirish (⚠️ savatcha yo'q!) |
| `cat f` / `less f` | Faylni ko'rish |
| `head -n 5 f` / `tail -n 5 f` | Boshi / oxiri |
| `tail -f log` | Log'ni jonli kuzatish |
| `nano f` | Muharrir |
| `grep "so'z" f` / `grep -rn "so'z" .` | Matn qidirish |
| `find . -name "*.py"` | Fayl qidirish |
| `wc -l f` | Qatorlar soni |
| `chmod +x f` / `chmod 755 f` | Ruxsatlar |
| `whoami` / `id` | Men kimman? |
| `history` | Buyruqlar tarixi |
| `man ls` / `ls --help` | Yordam |
| `cmd1 \| cmd2` | Pipe: birining natijasi ikkinchisiga |
| `cmd > f` / `cmd >> f` | Faylga yozish / qo'shish |
