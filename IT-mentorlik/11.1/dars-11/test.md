# 11-dars tezkor test

1. Prettier va ESLint farqi? — Prettier formatlaydi, ESLint xato va yomon amaliyotlarni topadi
2. AAA nima? — Arrange, Act, Assert
3. `toBe` va `toEqual` farqi? — toBe qat'iy tenglik (===), toEqual obyekt/massiv mazmunini solishtiradi
4. Chegaraviy holatga misol? — Bo'sh massiv, 0, chegara qiymati (499 999 va 500 000)
5. Xato chiqishini test qilish? — `expect(() => fn()).toThrow()`
6. Nima uchun unit testlar piramidaning pastida (eng ko'p)? — Tez, arzon va aniq
