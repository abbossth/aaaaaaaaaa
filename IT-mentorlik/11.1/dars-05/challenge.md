# 5-dars challenge: "Commit tarjimoni" 🕵️

**Vaqt:** 14 daqiqa | **Format:** jamoalar

## 1-raund: Diff → commit xabari (7 daqiqa)
Mentor ekranda 5 ta `git diff` ko'rsatadi (`kod/difflar.md`). Jamoalar har biri uchun eng aniq Conventional Commit xabarini yozadi.
Baholash: tur to'g'ri +1, soha mantiqli +1, tavsif aniq +1.

## 2-raund: "Atomic yoki yo'q?" (7 daqiqa)
Mentor 5 ta commit tavsifini o'qiydi. Jamoalar "✅ atomic" yoki "❌ bo'lish kerak" kartochkasini ko'taradi va ❌ bo'lsa, qanday bo'lish kerakligini aytadi.
1. "Login formasi va uning testlari" — ✅ (bitta feature)
2. "Navbar rangi, footer matni va API bug" — ❌ (3 ta commit)
3. "Barcha fayllarda probel formatlash" — ✅ (`style:`)
4. "Yangi sahifa + package.json yangilanishi (kerakli kutubxona)" — ✅
5. "Bug fix + yangi feature + README" — ❌

**XP:** 🥇 +20 · 🥈 +10 · 🥉 +5
