# 5-dars uyga vazifa

## Majburiy (+10 XP)
1. Feature branch'ingizda ishni davom ettiring (kamida 3 ta atomic commit). Keyingi darsda PR ochasiz.
2. Jamoa `CONTRIBUTING.md` ni tugatadi va main'ga qo'shadi.

## Qo'shimcha (+10 XP)
3. `semantic-release` yoki `release-please` vositasi Conventional Commits'dan qanday qilib avtomatik versiya va CHANGELOG yaratishini o'qing. Semantic Versioning'dagi `MAJOR.MINOR.PATCH` qaysi commit turlari bilan bog'liq? (`feat` → MINOR, `fix` → PATCH, `BREAKING CHANGE` → MAJOR)
