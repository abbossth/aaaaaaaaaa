# 5-dars amaliy topshiriq

## 🟢 Oson (+5 XP) — individual
Quyidagi commit xabarlarini Conventional Commits formatiga o'giring (daftarga):
1. `tuzatdim` (login tugmasi telefonda ishlamayotgan edi)
2. `yangi narsa` (foydalanuvchi profili sahifasi qo'shildi)
3. `readme` (o'rnatish bo'yicha yo'riqnoma qo'shildi)
4. `kodni tozaladim` (takrorlanayotgan fetch funksiyasi alohida faylga chiqarildi)
5. `test` (ro'yxatdan o'tish formasi uchun testlar qo'shildi)

## 🟡 O'rta (+10 XP) — jamoaviy
1. Jamoa reposida **branch protection** yoqing: main'ga to'g'ridan-to'g'ri push taqiqlanadi, PR va 1 ta approve talab qilinadi.
2. Jamoa `CONTRIBUTING.md` faylini yozadi (`kod/CONTRIBUTING-shablon.md` asosida): strategiya, branch nomlash va commit qoidalari.

## 🔴 Qiyin (+20 XP) — individual
3. O'z issue'ingiz uchun `feature/...` branch yarating. Kamida **3 ta atomic commit** qiling (Conventional Commits formatida) va push qiling. PR'ni hali ochmang, keyingi darsda ochamiz!
4. `git add -p` bilan bitta faylning faqat bir qismini commit qilib ko'ring.
