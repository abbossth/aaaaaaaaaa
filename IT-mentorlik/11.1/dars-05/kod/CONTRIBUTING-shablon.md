# Hissa qo'shish qoidalari (CONTRIBUTING)

## Branching: GitHub Flow
- `main` har doim ishlaydigan holatda bo'ladi.
- Har bir vazifa uchun issue ochiladi va shu issue uchun alohida branch yaratiladi.
- main'ga faqat Pull Request orqali, kamida 1 ta approve bilan merge qilinadi.

## Branch nomlash
`<tur>/<qisqa-tavsif>`: `feature/login-form`, `fix/navbar-mobile`, `docs/readme`

## Commit xabarlari (Conventional Commits)
`<tur>(<soha>): <tavsif>`
Turlar: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`

## Pull Request
- Sarlavha commit formatida bo'ladi.
- Tavsifda: nima, nega, qanday tekshirildi, `Closes #N`.
- Katta PR'lardan qoching: 400 qatordan kam bo'lsin.
