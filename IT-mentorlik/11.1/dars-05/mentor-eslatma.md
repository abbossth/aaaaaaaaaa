# 5-dars mentor eslatmasi

- Commit xabarlarini **ingliz tilida** yozish tavsiya etiladi (sanoat standarti). Lekin o'zbek tilida yozilsa ham format saqlansa, qabul qiling.
- Branch protection bepul **public** repolarda ishlaydi. Private repoda cheklangan bo'lishi mumkin. Jamoa repolarini public qiling (portfolio uchun ham foydali) yoki GitHub Education orqali Team rejimini oling.
- Protection yoqilgandan keyin o'quvchilar main'ga push qila olmaydi va bundan hayron bo'lishadi. Bu yaxshi o'rganish lahzasi.
