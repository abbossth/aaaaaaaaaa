# 3-dars challenge: "Git vaqt mashinasi" ⏳

**Vaqt:** 15 daqiqa | **Format:** individual

Mentor tayyor repo beradi (yoki o'quvchilar `kod/challenge-setup.sh` ni ishga tushiradi). Unda 8 ta commit bor. Topshiriqlar:

1. Eng birinchi commit xabari nima? (`git log --oneline`, oxirgi qator)
2. `sir.txt` fayli qaysi commit'da qo'shilgan? (`git log --oneline -- sir.txt`)
3. `sir.txt` o'chirilgan. Uning ichidagi maxfiy so'z nima edi? (`git show <commit>:sir.txt`)
4. `index.html` dagi sarlavhani kim o'zgartirgan? (`git log -p index.html` yoki `git blame index.html`)
5. Repoda nechta branch bor va ulardan qaysi biri hali merge qilinmagan? (`git branch -a`, `git branch --no-merged`)

**Birinchi bo'lib 5 ta to'g'ri javob bergan:** +30 XP, 2-o'rin +20, 3-o'rin +10.
