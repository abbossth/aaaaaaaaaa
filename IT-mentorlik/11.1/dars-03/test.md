# 3-dars tezkor test

1. Faylni staging'ga qo'shish? — `git add`
2. Yangi branch yaratib unga o'tish? — `git switch -c nom` (yoki `git checkout -b nom`)
3. Commit tarixini qisqa ko'rish? — `git log --oneline`
4. Qaysi fayl hech qachon GitHub'ga push qilinmasligi kerak? — `.env` (parollar, kalitlar), `node_modules/`
5. `git push` "rejected" bo'lsa, nima qilish kerak? — Avval `git pull`, keyin yana `git push`
6. O'chirilgan fayl mazmunini tarixdan qanday ko'rish mumkin? — `git show <commit>:fayl`
