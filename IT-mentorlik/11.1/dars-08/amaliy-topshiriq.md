# 8-dars amaliy topshiriq: To-Do CLI

## 🟢 Oson (+5 XP)
1. `node -v`, `npm -v` ni tekshiring. `node` REPL'da `2 ** 53`, `[1,2,3].map(x => x * 2)` ni sinang.
2. `salom.js`: `process.argv` dan ism olib, `Salom, Aziz!` deb chiqarsin (`node salom.js Aziz`).
3. `math.js` modulidan `qosh`, `ayir` funksiyalarini eksport qilib, `app.js` da import qiling.

## 🟡 O'rta (+10 XP)
4. `todo-cli` papkasida `npm init -y` qiling, `"type": "module"` qo'shing va `npm install chalk` qiling.
5. `add` va `list` buyruqlarini yozing (`kod/todo-cli/index.js` ga qarab emas, avval o'zingiz urinib ko'ring!). Ma'lumot `todos.json` faylida saqlansin.
6. `package.json` ga `"start"` skriptini qo'shing.

## 🔴 Qiyin (+20 XP)
7. `done`, `remove` va `clear` (bajarilganlarni o'chirish) buyruqlarini qo'shing.
8. Muddat qo'shing: `add "Test" --due 2026-10-15`. `list` da muddati o'tganlar qizil rangda chiqsin.
9. Loyihani GitHub'ga push qiling (`.gitignore` bilan!) va README yozing.
