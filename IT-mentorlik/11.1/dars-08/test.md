# 8-dars tezkor test

1. Node.js nima? — JavaScript'ni brauzerdan tashqarida (serverda) ishga tushiruvchi muhit
2. Buyruq qatori argumentlari qayerda saqlanadi? — `process.argv`
3. Faylni o'qish uchun qaysi modul kerak? — `fs`
4. `dependencies` va `devDependencies` farqi? — devDependencies faqat ishlab chiqishda kerak (test, lint)
5. `^5.3.0` nimani bildiradi? — 5.x.x ichidagi mos versiyalar (MAJOR o'zgarmaydi)
6. `node_modules` nega GitHub'ga yuklanmaydi? — Juda katta va `npm install` bilan qayta tiklanadi
