# 7-dars. 🏆 Git challenge: Learn Git Branching + "Merge conflict jangi 2.0"

**Guruh:** 11.1 | **Turi:** 🏆 Challenge | **Davomiyligi:** 80 daqiqa

## Maqsad
- 3–6-darslardagi Git bilimlarini o'yin orqali mustahkamlash: branch, merge, rebase, cherry-pick, remote.
- Git'ning ichki modelini (commit grafi, HEAD, branch = ko'rsatkich) vizual tushunish.
- "Xato qildim, endi nima qilaman?" holatlarini hal qilish: `restore`, `reset`, `revert`, `reflog`.
