# 7-dars tezkor test

1. Commit qilinmagan o'zgarishni bekor qilish? — `git restore fayl`
2. Push qilingan commit'ni xavfsiz bekor qilish? — `git revert`
3. Tugallanmagan ishni vaqtincha saqlash? — `git stash`
4. "Yo'qolgan" commit'larni topish? — `git reflog`
5. `reset --soft` va `reset --hard` farqi? — soft o'zgarishlarni saqlaydi, hard esa o'chiradi
6. Nega push qilingan tarixni qayta yozish xavfli? — Jamoadoshlarning lokal tarixi bilan ziddiyat chiqadi
