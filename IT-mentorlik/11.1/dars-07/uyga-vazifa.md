# 7-dars uyga vazifa

## Majburiy (+10 XP)
1. Learn Git Branching'da "Remote" bo'limining "To Origin And Beyond" qismidan 3 ta darajani o'ting.
2. O'zingiz uchun "Git cheat-sheet" (1 sahifa) tuzing va GitHub'dagi shaxsiy repo'ga `git-cheatsheet.md` qilib qo'ying.

## Qo'shimcha (+10 XP)
3. "Oh Shit, Git!?!" (ohshitgit.com) saytini o'qing. Bizning jadvalda yo'q bo'lgan 2 ta foydali holatni yozing.

## Keyingi darsga
Kompyuteringizga **Node.js LTS** o'rnating (nodejs.org). `node -v` va `npm -v` natijasini yuboring.
