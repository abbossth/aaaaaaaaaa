# 23-dars. Jira/Trello: backlog, user story, Sprint 1 rejasi

**Guruh:** 11.1 | **Turi:** 📘 Mavzu | **Davomiyligi:** 80 daqiqa
**Qo'llanma:** IV bob, "Jira, Trello, ClickUp bilan ish jarayoni" (oldinga ko'chirilgan)

## Maqsad
- Task-treker vositalarini taqqoslaydi: Jira, Trello, ClickUp, GitHub Projects.
- Sifatli user story yozadi: INVEST mezonlari va qabul qilish mezonlari (acceptance criteria).
- Story'larni baholaydi (story points, "Planning Poker") va MoSCoW bilan ustuvorlik beradi.
- Sprint Planning o'tkazadi: Sprint Goal, Sprint Backlog, vazifalarni taqsimlash.
- Board'ni sozlaydi (label, assignee, due date) va GitHub bilan bog'laydi.
