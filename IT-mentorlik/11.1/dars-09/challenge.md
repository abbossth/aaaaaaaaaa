# 9-dars challenge: "Code Smell bingo" 👃🎯

**Vaqt:** 16 daqiqa | **Format:** jamoalar

1. Har bir jamoa **boshqa jamoaning** GitHub reposidagi kodni (landing page, To-Do CLI) yoki mentor bergan kodni ko'rib chiqadi.
2. Bingo kartasidagi smell'larni topadi. Har bir topilgan smell uchun: fayl, qator va qanday tuzatish kerakligi yoziladi.
3. Bir qator (gorizontal, vertikal yoki diagonal) to'lsa — "BINGO!" deb baqiriladi 😄

| | | |
|---|---|---|
| Noaniq nom (`data`, `x`, `temp`) | Sehrli son | Takrorlangan kod blok |
| 20+ qatorli funksiya | 3+ darajali ichma-ich `if` | Kommentga olingan "o'lik" kod |
| "Nima"ni tushuntiruvchi keraksiz izoh | 4+ parametrli funksiya | `console.log` qolib ketgan |

**Qoida:** smell'ni topish — tanqid emas, yordam. Topilganlarni jamoaga **issue** qilib yozing (4-darsdagi shablon bilan). Hurmat bilan!

**XP:** Birinchi BINGO 🥇 +20 · 🥈 +10 · 🥉 +5 · Har bir to'g'ri yozilgan issue +2
