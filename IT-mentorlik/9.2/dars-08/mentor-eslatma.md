# 8-dars mentor eslatmasi

## Ko'p uchraydigan xatolar
| Xato | Yechim |
|---|---|
| `l = l.sort()` → `None` | `sort()` joyida ishlaydi va hech narsa qaytarmaydi |
| Sikl ichida ro'yxatdan element o'chirish → elementlar "o'tkazib yuboriladi" | Nusxa ustida aylanish (`for x in l[:]`) yoki comprehension bilan filtrlash |
| `remove` mavjud bo'lmagan element uchun → ValueError | Avval `if x in l` bilan tekshirish |
| `b = a` tuzog'i | Jonli demo albatta ko'rsatilsin. Bu keyinchalik funksiyalarga ro'yxat uzatishda juda muhim |

## Maslahat
Havola tuzog'ini **pythontutor.com** saytida vizual ko'rsating: o'zgaruvchilar va ob'ektlar strelkalar bilan chiziladi. Juda tushunarli bo'ladi.
