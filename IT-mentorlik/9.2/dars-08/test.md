# 8-dars tezkor test

1. `[1, 2, 3][::-1]`? — `[3, 2, 1]`
2. `append` va `extend` farqi? — append bitta elementni qo'shadi, extend esa ro'yxatdagi barcha elementlarni
3. `l.sort()` va `sorted(l)` farqi? — sort joyida o'zgartiradi va None qaytaradi, sorted yangi ro'yxat qaytaradi
4. `[x * 2 for x in range(3)]`? — `[0, 2, 4]`
5. Tuple va list farqi? — Tuple o'zgarmas
6. `a = [1]; b = a; b.append(2); print(a)`? — `[1, 2]`
7. `a, b = b, a` nima qiladi? — Qiymatlarni almashtiradi
