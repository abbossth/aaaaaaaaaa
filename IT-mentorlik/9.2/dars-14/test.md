# 14-dars tezkor test

1. Klass va obyekt farqi? — Klass — chizma/qolip, obyekt — undan yaratilgan nusxa
2. Konstruktor metodi nomi? — `__init__`
3. `self` nima? — Metod chaqirilgan obyektning o'zi
4. Class atributi va instance atributi farqi? — Class atributi hamma obyektlarga umumiy, instance atributi har bir obyektniki
5. Obyekt atributlarini dict ko'rinishida ko'rish? — `obj.__dict__`
6. OOP'ning 4 tamoyili? — Inkapsulyatsiya, meros, polimorfizm, abstraksiya
