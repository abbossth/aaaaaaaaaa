# 14-dars challenge: "Klass chizuvchi" 🎨

**Vaqt:** 14 daqiqa | **Format:** jamoalar

Mentor real hayotiy "narsa"ni aytadi. Jamoalar 2 daqiqada qog'ozda **klass diagrammasini** chizadi:
```
┌──────────────────┐
│     Klass nomi    │
├──────────────────┤
│ atributlar        │
├──────────────────┤
│ metodlar()        │
└──────────────────┘
```
