# 24-dars. 🤖 AI bot: botga LLM ulash (Gemini API)

**Guruh:** 9.2 / 9.3 | **Turi:** 🤖 AI | **Davomiyligi:** 80 daqiqa

## Maqsad
- LLM API qanday ishlashini tushunadi: so'rov (prompt) → model → javob; tokenlar, limitlar, narx.
- **System prompt** (tizim ko'rsatmasi) orqali botga "shaxsiyat" va cheklovlar beradi.
- Suhbat tarixini (context) saqlab, ko'p bosqichli dialog quradi.
- API kalitini xavfsiz saqlaydi va limitlarni (rate limit) hisobga oladi.
- AI xavfsizligini tushunadi: prompt injection, noto'g'ri ma'lumot, shaxsiy ma'lumotlar.
- "Aqlli yordamchi" bot yaratadi: masalan, Python o'qituvchisi bot.
