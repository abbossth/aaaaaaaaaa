# 30-dars tezkor test

1. CRUD'dagi "R" qaysi SQL buyrug'i? — `SELECT`
2. Yangi qo'shilgan qatorning id'sini olish? — `RETURNING id`
3. `WHERE` siz `DELETE FROM talabalar;` nima qiladi? — Hamma qatorlarni o'chiradi
4. O'zgarishlarni bekor qilish? — `BEGIN` ... `ROLLBACK`
5. NULL qiymatni tekshirish? — `IS NULL` (`= NULL` emas!)
6. Natijani 5 ta qator bilan cheklash? — `LIMIT 5`
