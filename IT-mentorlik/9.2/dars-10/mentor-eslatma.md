# 10-dars mentor eslatmasi

## Ko'p uchraydigan xatolar
| Xato | Yechim |
|---|---|
| `print` va `return` chalkashligi: funksiya `print` qiladi, natija esa `None` | "Funksiya natijani qaytarishi kerak, chiqarish — chaqiruvchining ishi" |
| Funksiya e'lon qilingan, lekin chaqirilmagan | `main()` ni unutish |
| Default qiymat sifatida ro'yxat: `def f(l=[])` | Klassik tuzoq! Kuchli o'quvchilarga ko'rsating (`None` ishlating) |
| `str \| None` Python 3.9 va eski versiyalarda ishlamaydi | Python 3.10+ ekanini tekshiring |

## Maslahat
- `testlar.py` challenge'i — TDD'ga birinchi kirish. Keyinroq (48-dars) pytest bilan davom ettiramiz.
- 11-darsda v3 (fayl + try/except) qilinadi. v2 kodini saqlab qo'yishni eslatib qo'ying.
