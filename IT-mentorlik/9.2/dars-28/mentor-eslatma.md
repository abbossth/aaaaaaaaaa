# 28-dars mentor eslatmasi

- Normalizatsiyani nazariy (1NF/2NF/3NF definitsiyalari) emas, **misol orqali** o'rgating. "Jadval shifokori" shu uchun.
- dbdiagram.io DBML sintaksisi oson. Kerak bo'lsa, `kod/maktab.dbml` ni to'g'ridan-to'g'ri nusxalash mumkin.
- **Keyingi dars uchun:** PostgreSQL o'rnatish ko'p vaqt oladi. Iloji bo'lsa, maktab kompyuterlariga oldindan o'rnatib qo'ying. Muqobillar: Docker (`docker run -e POSTGRES_PASSWORD=... -p 5432:5432 postgres:16`), onlayn — **neon.tech** yoki **supabase.com** (bepul bulutli PostgreSQL), **sqliteonline.com** (PostgreSQL rejimi).
