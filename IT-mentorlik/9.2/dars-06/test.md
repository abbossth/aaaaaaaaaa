# 6-dars tezkor test

1. Xatolarning 3 turi? — Sintaksis, bajarilish (runtime), mantiqiy
2. Qaysi turdagi xato eng xavfli va nega? — Mantiqiy: dastur ishlaydi, lekin noto'g'ri natija beradi va buni hech kim sezmasligi mumkin
3. Traceback'ni qaysi tomondan o'qish kerak? — Pastdan (oxirgi qatordan)
4. `NameError` qachon chiqadi? — Aniqlanmagan o'zgaruvchidan foydalanilganda
5. `(a + b + c) / 3` va `a + b + c / 3` farqi? — Amallar ustuvorligi: ikkinchisida faqat c bo'linadi
6. VS Code'da qadamma-qadam bajarish tugmasi? — F10 (Step Over)
