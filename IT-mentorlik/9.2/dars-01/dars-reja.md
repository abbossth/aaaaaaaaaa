# 1-dars. Tanishuv, diagnostika, Back-end va DevOps kasblari, yo'l xaritasi, XP liga

**Guruh:** 9.2 / 9.3 | **Turi:** 📘 Mavzu | **Davomiyligi:** 80 daqiqa

## Maqsad
- Back-end va DevOps muhandislari nima qilishini real misollar bilan tushuntirish.
- Yil yo'l xaritasini ko'rsatish: Python → OOP → Bot → Linux → PostgreSQL → FastAPI → Docker/CI/CD → startap.
- Python, Git va terminal bo'yicha diagnostika o'tkazish.
- XP liga va 9.2 vs 9.3 guruhlararo ligasini e'lon qilish.
