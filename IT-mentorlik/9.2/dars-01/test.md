# 1-dars diagnostika testi (15 savol)

**Python**
1. `print(type(3.14))` natijasi? — `<class 'float'>`
2. `input()` qanday tipdagi qiymat qaytaradi? — `str`
3. `10 // 3` va `10 % 3`? — `3` va `1`
4. Ro'yxatga element qo'shish metodi? — `append()`
5. `for i in range(2, 10, 3): print(i)` nimalarni chiqaradi? — 2, 5, 8
6. Funksiya qaysi kalit so'z bilan e'lon qilinadi? — `def`
7. Lug'at (dict)dan qiymat olish: `d = {"a": 1}`? — `d["a"]` yoki `d.get("a")`

**Git / terminal**
8. Yangi repo yaratish buyrug'i? — `git init`
9. O'zgarishlarni saqlash (commit)? — `git commit -m "..."`
10. GitHub'ga yuborish? — `git push`
11. Papkaga kirish buyrug'i? — `cd`
12. Papkadagi fayllar ro'yxati (Linux/Git Bash)? — `ls`

**Umumiy**
13. HTTP status 404 nimani bildiradi? — Topilmadi
14. JSON nima? — Ma'lumot almashish uchun matnli format (kalit: qiymat)
15. Back-end va front-end farqi? — Back-end server tomoni, front-end foydalanuvchi ko'radigan tomon

**Natija:** 13–15 kuchli · 8–12 o'rta · 0–7 asoslarni takrorlash kerak
