# 13-dars slaydlari: Jamoaviy CLI loyiha 🚀

## 1-slayd
**80 daqiqa · 3 kishi · 1 ta ilova**

## 2-slayd — Loyiha variantlari
🎮 Terminal RPG o'yin · 📚 Kutubxona tizimi · 💰 Shaxsiy byudjet · 🧠 Viktorina · 🏫 Sinf jurnali · 🍔 Kafe buyurtma tizimi · 💡 O'z g'oyangiz

## 3-slayd — Majburiy talablar
✅ Menyu (`while` + `match`)
✅ Kamida 5 ta funksiya
✅ JSON faylda saqlash
✅ `try/except` — hech qachon qulamasin
✅ GitHub: har bir a'zo kamida 2 ta commit

## 4-slayd — Jamoada Git 🤝
1. Tech lead: repo + collaborator'lar
2. Hamma: `git clone`
3. Har kim **o'z faylida** ishlaydi (konfliktlar kam bo'ladi!)
4. Har 15 daqiqada: `git pull` → `git add .` → `git commit -m "..."` → `git push`

## 5-slayd — Fayllarni taqsimlash
```
loyiha/
├── main.py        ← tech lead (menyu)
├── storage.py     ← 2-a'zo (JSON saqlash/yuklash)
├── logic.py       ← 3-a'zo (asosiy funksiyalar)
└── data.json
```

## 6-slayd — Demo formati (3 daqiqa)
1. Nima uchun? (1 jumla)
2. Jonli ishga tushirish
3. "Wow" funksiya
