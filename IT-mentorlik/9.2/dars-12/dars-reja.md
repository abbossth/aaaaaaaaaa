# 12-dars. 🤖 AI pair programming: AI bilan kod yozish, AI'dan code review olish

**Guruh:** 9.2 / 9.3 | **Turi:** 🤖 AI | **Davomiyligi:** 80 daqiqa

## Maqsad
- LLM qanday ishlashini (token, kontekst, ehtimol, gallyutsinatsiya) sodda darajada tushunadi.
- AI'dan dasturchi sifatida foydalanadi: kod yozdirish, xatoni tushuntirish, code review, test yozish, refaktoring.
- Samarali prompt texnikalarini qo'llaydi: rol, kontekst, cheklovlar, misollar (few-shot), bosqichma-bosqich so'rash.
- AI kodini tanqidiy baholaydi: xavfsizlik, noto'g'ri kutubxonalar, "o'ylab topilgan" funksiyalar.
- AI yordamida I bob bilimlari asosida yangi CLI ilova yaratadi va uni o'zi tushuntirib bera oladi.
